## 0. 定位与硬性原则

- **纯 Rust**：物理核心零 C++、零 Bevy 类型。游戏引擎（Bevy）只做渲染与壳，
  通过本文 §9 的接口消费物理。〔继承原 15.18 禁止项 1-2〕
- **确定性优先**：固定步长 + 严格 f32 + 有序归约；回放 bit 级一致（§5）。
- **模块化**：crate 依赖图有向无环、无全局状态、无隐式耦合；每个模块可独立
  测试/替换/禁用（§6）。
- **真实度可配置**：§4 的每一档都是「技术名 + 参数数值 + 性能代价」三元组，
  不使用「高/中/低」这类无定义形容词。
- **性能目标分层**：最低通过 / 目标通过 / 卓越通过三档（§3），参考硬件固定。

**与路线 B 的关系（不推翻既有设计）**：Rapier 权威内核（B1-B3 已落地）继续服役
至 vxl_phys 通过对等验收；Rapier 同时是 vxl_phys 的**对照金样**（原路线 C 的
「Rapier 做金样」条款升级为常设）。avian 按游戏侧 B5 退役，与引擎进度解耦。

## 2. 求解器本体（七子系统，技术选型定案）

1. **刚体状态与质量属性**：位置/旋转/线角速度/inv_mass/inv_inertia；惯性张量
   由形状解析式（盒/球/圆柱/胶囊）+ 复合体平行轴叠加。
2. **积分**：半隐式欧拉；固定 60 Hz 基础步，子步 1/2/4/8/16 可配；批量积分
   SIMD 化（§7）。
3. **宽相**：增量 AABB 树（bvh2 风格）为主，均匀大世界叠加空间哈希网格；
   重建与遍历 job 并行。
4. **窄相**：GJK+EPA（凸体）、SAT（盒/定向盒）、高度场特化（列裁剪 + 局部
   采样）、网格 = BVH + 凸分解（VHACD 预处理）；接触流形 4 点裁剪。
5. **刚体求解**：**TGS-Soft**（time-of-impact 分级 + 软约束，Box2D v3 同族），
   warm starting；摩擦 = 摩擦锥；**关节**：铰链/球窝/滑块/固定/弹簧/马达/
   齿轮/齿条/绳索（距离约束链），可断裂（应力阈值）/可限位/可阻尼。
6. **岛与休眠**：并查集分岛，岛内并行求解（§7 调度）；休眠阈值见 §4.11。
7. **CCD**：扫掠式，按速度阈值选择性启用（§4.12）。

软体/布料/流体/车辆等专项模块的技术选型与参数在 §4 真实度档位中给出。

## 4. 真实度档位（模糊词 → 客观参数 + 技术名）

以下每档都是「技术 + 参数 + 代价」三元组。**运行时切换不重启，状态一致**
（切换点 = 当前 tick 末，受影响求解器状态按保守策略重建）。

### 4.1 求解器迭代
TGS-Soft 速度迭代次数 ∈ {1, 4, 8, 16, 32, 64}。代价：堆叠稳定度与能耗，
16 为默认；64 档仅供 1 万体以内场景。

### 4.2 子步
每 60Hz 帧子步 ∈ {1, 2, 4, 8, 16}。子步 N = 求解精度 ×N、成本 ×N；
软体/布料耦合场景建议 ≥4。

### 4.3 碰撞精度（替换「低中高超高」）
- 接触 skin（_speculative margin_）：0.02 / 0.01 / 0.005 / 0.002 m 四档；
- GJK 收敛容差：1e-4 / 1e-5 / 1e-6 m；
- CCD 触发速度阈值：10 / 5 / 2 / 1 m/s。
代价：窄相耗时与皮肤滑入量。

### 4.4 摩擦模型
- **库仑（单 μ）**：每材质一个摩擦系数，默认档；
- **静+动（μs, μk）**：两系数 + 临界速度 v_crit（Stribeck 线化）；
- **各向异性**：两主轴 μ1/μ2 + 方向角（传送带/履带用）。
实现位置：接触约束的摩擦锥方向与目标速度缩放，不改求解器结构。

### 4.5 恢复系数
e ∈ [0,1] 每材质对（取 max 组合律），附**恢复速度阈值**（默认 1 m/s：
低于阈值的碰撞 e 视作 0，防微弹跳抖动）。

### 4.6 软体（技术：XPBD）
粒子 + XPBD 距离/体积约束（Müller et al. 2020 XPBD；compliance α 单位 m/N）。
- 刚度档（α）：近刚 1e-7 / 硬 1e-6 / 标准 1e-5 / 软 1e-4 / 果冻 3e-4；
- 体积守恒：Müller 2007 压力约束（气压系数 k，粒子数预算 1e4~1e6）；
- 自碰撞：空间哈希 + 粒子半径 r（默认 0.05 m），开启代价 ≤50%〔目标〕；
- 与刚体耦合：粒子-刚体距离约束（Akinci 式边界处理）；
- 撕裂：应变 ε_break ∈ {0.3, 0.5, 1.0, ∞(不撕)}，超阈删约束并按质量分账。

### 4.7 布料（技术：XPBD 三组约束 + 面元气动力）
结构/剪切/弯曲三组距离约束（compliance 各自独立可配）；风 = 每三角面
相对风力 F = ½ρ·Cd·A·(v_wind−v_tri)（Bridson 线化气动力）；撕裂同 §4.6；
与角色/刚体耦合 = 钉扎约束 + 粒子-刚体碰撞。预算：10 万三角 @GPU 60 FPS。

### 4.8 流体（按技术族分档，不用形容词）
- **CPU SPH**：WCSPH + XSPH 黏度（Monaghan 核），30 万粒 @30 FPS 档；
- **GPU PBF**（Müller 2013 Position Based Fluids，poly6/spiky 核，密度约束
  迭代 3~4）：1000 万粒目标档；tensile instability 用 spiky 梯度抑制；
- **GPU FLIP/APIC**（PIC/FLIP 传输 + APIC 仿射速度，抗耗散）：高精档，
  配稀疏哈希网格（512³ 活跃格预算）；
- 与刚体耦合：Akinci 边界粒子两层（体积/压力）；与软体耦合同通道。

### 4.9 可破坏地形与建筑坍塌
- 地形：高度场体素账本（与 404 现役挖掘账本同构）+ 柱状支撑图快速重算；
- 预断裂：Voronoi 分片（质心排序确定性）离线/装载期生成；
- 运行时断裂：冲击能量阈值 E_threshold（按材质 J 表），触发 Voronoi 细分
  一层；碎片继承动量；
- 结构稳定性：连接约束网络按应力断裂 → 连锁坍塌；碎片休眠阈值放宽一档。
- 档位 = 碎片预算 {1 千, 1 万, 10 万, 100 万〔目标 GPU〕} + 细分层数 {1,2,3}。

### 4.10 车辆（技术：射线悬挂 + 刷子轮胎模型）
悬挂 = 轮心射线（ stiffness/damping/行程三参数，404 现役参数迁入）；
轮胎 = 简化刷子模型（峰值侧偏角 α_peak、载荷敏感系数、纵滑摩擦曲线 μ(s)）；
传动 = 引擎扭矩曲线 + 齿比表 + 差速（开放/限滑系数）；漂移 = 侧滑角阈值+
回正力矩项。档位：街机（线性轮胎 + 包络钳制）/ 真实（全刷子模型 + 载荷转移）。

### 4.11 休眠
线性 0.04 m/s / 角速 0.05 rad/s（Box2D 默认同族），睡眠计时 0.5 s；
可配 {激进 0.1/0.12, 默认, 保守 0.02/0.025}。

### 4.12 CCD
关 / 全体 / 选择性（速度阈值 + 尺寸比三判据），默认选择性。

### 4.13 LOD（求解降档）
三因子线性组合：距离 d（hysteresis ±10%）、屏幕占比 s、重要性 w（任务/玩家
标记）→ 降档动作 ∈ {子步减半, 迭代降一档, 休眠加速}，不改变静态几何。

### 4.14 确定性模式
严格模式 = 关 FTZ/DAZ、禁 FMA 重排（sim 路径标 `#[inline(never)]` 隔离）、
岛内约束排序固定（按生成索引）；性能模式允许重排。性能差 ≤30%〔目标〕。

### 4.15 预设（游戏侧命名引用，参数全量见上）
| 预设 | 迭代 | 子步 | 精度 | 摩擦 | 软体 α | 流体族 | 破坏预算 |
|---|---|---|---|---|---|---|---|
| 街机 | 4 | 1 | skin 0.02 | 库仑 | 不启用 | 不启用 | 1 千 |
| 平衡 | 8 | 2 | 0.01 | 静+动 | 1e-5 | SPH 10 万 | 1 万 |
| 真实 | 16 | 4 | 0.005 | 各向异性 | 1e-6 | PBF GPU | 10 万 |
| 极致 | 32 | 8 | 0.002 | 各向异性 | 1e-7 | FLIP | 100 万 GPU |

## 5. 确定性

- 固定 60 Hz + 可配子步；**渲染帧率与物理解耦**。
- 严格 f32：禁 fast-math、FTZ/DAZ 关闭、sim 路径无 platform intrinsics、
  归约有序（岛内定序）；跨岛顺序无关（岛间无浮点交互）。
- 回放 = 输入序列重放 + 每 60 tick 状态哈希（xxh3 规范化序列化）。
- 跨平台矩阵：x86_64(win/linux) × {MSVC, GCC, Clang} × {O0, O2, O3, LTO}，
  aarch64(linux) 同跑；哈希不一致 = 阻断提交。
- 网络同步：引擎只保证确定性步进与状态序列化；快照/回滚/插值/压缩由
  消费方（404 = vxl_protocol 现役链路）实现。

## 6. 并发

- 单一 JobSystem（工作窃取 + 无锁队列），CPU 与 GPU 提交共用；**禁止
  Rayon 与自研池混用**。
- 岛级并行求解 + 宽相/窄相分块并行；Unsafe 并发过 loom，全库过 miri 子集
  与 TSan；编译期以 Safe Rust 优先。
- 正确性门：miri/loom/TSan 全绿为提交门（CI）。

## 7. SIMD / 汇编（三层，≥5% 收益律）

1. `core::arch` intrinsics 覆盖 ~90% 热点（约束求解内循环/GJK 支持函数/
   BVH 遍历/批量积分/接触流形）；
2. `std::simd`（或 ISPC 风格抽象）过渡层；
3. 手写汇编仅限 <1% 顶点热点，且必须：`is_x86_feature_detected!` 分发 +
   标量回退 + 基准证明优于 intrinsics ≥5% + 逐条注释（意图/寄存器/clobber/
   平台差异）+ 跨平台测试。四者缺一即禁止合入。
   平台面：x86_64（SSE4.2/AVX2/AVX-512 分发）与 aarch64（NEON）双路；
   wasm32 走标量回退。

## 8. GPU（纯 Rust 路线）

- 统一入口：自有 trait `PhysGpuBackend`；主实现 = **wgpu**（Vulkan/Metal/
  DX12/WebGPU）；着色器 = **rust-gpu** → SPIR-V。
- NVIDIA 极致路径：**cuda-oxide** SIMT 内核 + C ABI 主机桥（仅该路径允许
  独立后端）。
- 适用域：大规模粒子/流体/布料/批量碰撞/批量 memfind。**必须 CPU 回退且
  结果一致**（同档参数下位姿哈希一致，容差 = 严格模式的量化容差）；必须
  出 GPU vs CPU 对比数据。禁止单一厂商绑定。

## 9. 接口与 FFI

- Rust 消费方：原生 API（同语言零 FFI）；404 侧 = `PhysicsBackend` trait
  切换（见适配文档）。
- C ABI（仅编辑器/外部工具）：**批量**接口（整世界快照/指令块进出），
  禁止每对象每帧跨界；结构体带 `size: u32, version: u32` 头；错误一律
  错误码（异常/panic 不跨界，panic=unwind catch 转码）。
- 序列化：二进制版本化（schema 版本字段 + 拒绝不兼容），零拷贝读路径
  （bytemuck 校验后）。

## 10. 内存子串工具（vxl-phys-memfind）

**用途限定**：资产管线索引、调试符号定位、序列化定位、碰撞模式查找；
**不进求解核心**。
- Rust 通用：`memchr::memmem`；多模式：`aho-corasick`；GPU 批量：自研
  cuda-oxide/wgpu kernel（对标 StringZilla CUDA）。
- 汇编仅限固定短 needle 热点（§7 三层律约束）。
- 指标〔目标，方法 = Criterion 固定数据集，对比报告必须含标准库基线〕：
  1B needle/64KB haystack ≥50 GB/s；短 needle ≥10 GB/s；长 needle ≥4 GB/s；
  多模式 1 万模式/1 MB ≥1 GB/s；GPU 批量 ≥100 GB/s。
- 回退：无 SIMD/无 GPU → 标量路径正确性测试必跑。
