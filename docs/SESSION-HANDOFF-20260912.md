## 4. 技术结论存档（防回档丢失）

- **BVH 链化定律**：面积启发式插入对结构化插入序（网格行优先）会链化
  （树高 ≈ n/2；11k 体实测 8826；200 体网格行优先 93 vs 伪随机 35）。
  解法 = 确定性中位分裂全量重建（top-down 最长轴 + `select_nth_unstable_by`
  按（轴中心， body id）全序），触发条件 `n≥32 && (首帧 || 树高 > 3·log2(n)+16)`。
- **rebuild 陷阱**：中位分裂后左右 body id 不连续，`leaf_of` 必须全量传入按
  body id 寻址；叶子绝不能走 `insert()`（它挂 self.root 且旋转，与手工接线互踩）。
- **rotate_up 槽位接法**（已修 bug）：child 取代 a 的位置，child 较高子树让位
  给 a，较低子树留在 child 另一侧。
- **材质组合律**：μ = √(μa·μb)（各向异性暂取均值，方向应用留 M2 传送带）；
  e = max，附恢复速度阈值；默认材质占槽 0，需与 config 同步（`with_broadphase`）。
- **CCD（M1 口径）**：三判据（速度阈值+尺寸比+目标侧仅静态/沉睡），默认关
  （threshold=INFINITY）；命中 = 保守推进钳位 + 法向速度清零（非弹性）；
  恢复系数完整路径随 M2 TGS-Soft 接入。
- **M0 基准健康口径**：health = {NaN=0, deep=0, max_depth, awake, contacts}。
