### 进度更新（2026-09-12 第三段：沸腾缺陷系统性定位 + 两项修复）

诊断工具（本段新增，随封档保留作回归工具）：
- `examples/diag_min.rs`：场景阶梯 + 能量审计（KE/PE/ΔE 逐 tick、分裂冲量位移

  地板 ±20 防盒掉落虚空污染统计。
- `examples/diag_col.rs`：单列逐 tick 追踪 + **逐体接触功审计**
  （ΔKE − 重力功 = 接触功；质量 = 密度×体积 = 125kg，逐位吻合验证过）。

**已排除项（证据链）**：
1. 并行路径无关：同场景 threads 1/2/8 结果**逐位相同**（含 dE 峰值、末态）。
2. 分裂冲量/偏置通道无关：baumgarte=0 全关后沸腾档与微抖档**完全照旧**。
3. 高度场窄相无关：盒地板（静态盒）与高度场沸腾行为相同。
4. 竖直链本身稳定：1×1 柱（5 盒）与 3 层/5 层柱均入睡，残差 0。
5. 场景阶梯：1×1 入睡；2×2 起出现持续微抖（顶层盒 |v|≈0.04 恰在睡眠阈，
   永不入睡）；4×4 恶化；10×10/20×20 沸腾。**无侧碰（横距 1.0）时仍不睡但
   有界（|v|≈0.16-0.19，微抖极限环）；横距 0.51（缝 ≤ skin 有贴面接触）与
   0.50（贴合）完全入睡；横距 0.52（缝 2cm，角点间歇接触）沸腾**——
   触发通道 = 角点接触对微抖的集体放大。
6. 收敛敏感性：iters=64 时 20×20 沸腾档基本收敛（awake 19/2000）——
   微抖幅度 ≈ GS 残差 × 重力增量（16 次迭代残留 ~15% → |v|_ss ≈ 0.03，
   与实测吻合）。

**已落地修复**：
7. **摩擦锥径向化**（`vxl-phys-solver`）：旧实现「逐轴 ±μ·pn 盒形钳制 + 事后
   径向缩放」→ 改为 Box2D v3 / Jolt 同族「逐轴求解后把累计切向向量投影到
   μ·pn 圆盘」。旧实现两轴独立饱和（角点模长 √2·μ·pn）后缩回，等效摩擦上限
   随求解序漂移，形成相干力矩。**隔离实验：μ=0/0.05 完美静止、μ=0.5 缓慢
   倾覆爬行（qz 单调增长）；修复后 2 列 μ=0.5 完全静止入睡（工作审计全零）。**
8. **对称扫掠**（正/反交替约束序 + 接触点序）：4 点面接触是冗余约束 + 强转动
   耦合，单向 GS 16 次迭代残留可观；对称后收敛率 ≈ ρ²。实测：20×20 沸腾档
   单 tick 能量注入峰值 2452 → 79-119 J；2 列 0.52 档 |v| 0.044 → 0.006。
   代价：横距 1.0 的孤立微抖档略变差（5/20 → 20/20 醒、|v| 0.116）——两档
   取舍，M1 目标档（密堆）优先。

### 进度更新（2026-09-12 第四段：沸腾缺陷根因③ = 歧管内收敛不足 → 修复）

**定位链（新工具 `examples/diag_eject.rs`：逐 tick 全体接触功 + 总注入列 + 泵能
体流形倾倒）**：
- 45 盒最小复现（3×3×5、横距 0.52）：总接触功常年为负（净耗散），**升级不是
  注入而是「失去支撑」**——t=265 起 #43 以 g·dt 精确自由落体（Σ功≈0 无接触，
  0.163 m/s per tick），落回后冲击再激励全堆：沸腾 = 弹射-落回自持循环；
- 弹射之因：盒子在「静止」堆里**横向蠕动 5-10 cm/s**（摩擦锥饱和 ±μ·pn，
  角点窄条接触斑上止不住）→ 滑入 2 cm 缝 → 顶层盒逐渐失去支撑；
- 蠕动之因：持续竖直微抖（角点窄条对滚转支撑弱）；微抖不衰减之因：
  **4 点面接触是冗余约束（4 约束/3 自由度）+ 强转动耦合，单向 GS 收敛慢**。
  证据：迭代阶梯 16 沸 / 24 静 / 32 又乱 / 48 近 / **64 完全入睡**。

**修复（根因③）**：**歧管内层扫掠** —— `PhysConfig::normal_inner`（默认 4）：
每个接触流形在外层每次迭代内对**法向 + 摩擦全通道**多扫 K 遍，歧管内收敛
≈ K×外层（16 外层 × K=4 ≈ 64 次全通道的等效在歧管内达成），偏置通道仍每点
一遍。实测：
- 45 盒档：**awake 0/45、|v| 0**（修前 6.2 m/s 沸腾）；
- 20×20 五层（2000 盒）：300 tick 残余混沌、600 tick |v| 0.135、**1200 tick
  awake 0/2000 完全入睡**（单调衰减，收敛时间 ~20s 是混沌衰减时标）；
- K=2 不够（45 盒 300 tick 未入睡）→ K=4 定案；K=1 即 M0 行为。

**定价（A/B 实测）**：8B 规模累计均值 79.7 → 138.9 ms（1.74×）；压力堆
p50 244.6 → 545.2 ms（2.2×）。**内层扫掠成本 = M1 性能目标（8B 33ms）的新
约束，T2/T3/T4 的预算需按此重排**（先稳定后提性能；不稳定时性能无意义）。

**验收（万级 25 层实测，2026-09-12 第四段末）**：`m1_pile 16 1 8 600 0`
（10 001 盒 20×20×25）**FAIL 且是另一量级的故障 regime**：t=100-300 剧烈坍塌
（|v|max 12-17 m/s、单 tick KE 2.2 MJ、深穿透 0.86、6327 体高速），t=600 时
|v| 已回落至 0.05 但 awake 9993、尾窗 p50 186ms。**代理场景**（25×10×10，
6m 高）：shock=0 时同样先坍塌（t=200 |v| 12.3、KE 2.24 MJ）后于 t≈600 平静
（|v| 0.051，但 awake 2267 微抖）；**shock 迭代（4/8）显著变差**（|v| 40-43、
盒飞出世界 y −80 以下）——M0 已有同向记录，**shock 路径确认不可用**。
**下一段主攻**：① 「坍塌」是否物理——**已定标（2026-09-13 金样对拍，见下）**；
② 坍塌期的深穿透（0.86 > 盒宽）如何被流形/冲量放大；③ 坍塌后微抖不入睡
（跨层链的收敛容量不足）。

**工具**：`gold-sample/`（独立包，自带 `[workspace]`——CI 的 `--workspace`

Rapier = 0.35.3 默认（TGS-Soft 4 迭代 + 软接触 + speculative 预测距离）。

**定标结论**：
1. **col45**：双引擎都完全入睡；末态参照体 max |Δpos| ≈ 2.5cm，且偏差结构
   可读——我们每层留 ~4mm 浮空缝、Rapier 每层压 ~2mm 软接触下沉。
2. **pile5（2000 盒）**：**Rapier t=50 全部入睡（|v|=0）**；我们 t≤300 沸腾

3. **tower25（2500 盒，12.5m）**：**Rapier 塔身完整、t=100 全部入睡（2500/
   2500）、高度带 [0.25,12.08] 保持**；我们 t=100-300 坍塌（|v|max 14.3、
   KE 3.6 MJ、顶部从 11.95 掉到 4.19）。
4. **结论：坍塌非物理，M1 判据（600 tick 入睡）成立且必须达到。** 差距的
   结构性解释：Rapier 的软接触把深堆承载分布到局部弹簧柔度（每层压 2mm 即
   达平衡），**不依赖跨层迭代链收敛**；我们的硬约束需要载荷沿 25 层逐次
   传播（外层 16 次远不够），内层扫掠只在歧管内生效。

**下一步 = T1 的 TGS-Soft 软约束完整形态**（计划已有项，现为最高优先级）：
每接触改造成「柔度 ω/ζ + gamma 阻尼」的软约束（参考 Rapier SpringCoefficients
/ Box2D v3 soft contact 语义），金样容差表作为验收基准（首档：col45 位置
2.5cm 内、pile5/tower25 入睡时点差距入容差表）。

### 进度更新（2026-09-13 第六段：软接触首版实验（未落地）+ Rapier 配方提取）

**从 rapier 0.35.3 源码提取的精确配方**（`SpringCoefficients`，逐行对齐；
`stash@{0}` 保存了我们的首版实现，可 pop 复用）：
- `ω = 2πf`；`erp_inv_dt = ω/(dt·ω + 2ζ)`；`erp = dt·erp_inv_dt`；
  `inv = 1/erp − 1`；`cfm_coeff = inv²/((1+inv)·4ζ²)`；`cfm = 1/(1+cfm_coeff)`；
- 每点：`rhs_wo_bias = max(0,dist)/dt`（speculative 项）；`rhs_bias =
  clamp(erp_inv_dt·dist, −3, 0)`；**穿透接触 cfm=1（硬投影）、speculative
  接触 cfm<1（软）**；
- 更新式：`λ ← cfm·(λ + m·(rhs − vn))`，钳 ≥ 0（与我们的重排逐式同构）；
- 参数：动态对 30 Hz / ζ=10；含静态侧 60 Hz / ζ=10；`max_corrective_velocity`
  3.0；**预测距离 0.02；接触回收（recycle）true、回收距离 0.05**。

**首版实现实测（本轮未落地，如实记录）**：45 盒更贴金样（末态 max|Δpos|
2.5cm → 1.4cm，我们开始像 Rapier 一样每层沉降）；**但 5 层堆回归沸腾**
（|v| 6.2 持续到 t=600）且塔更糟（弹射 43 m/s 出世界 y −91）。**结论：
单独换软接触公式不够——Rapier 的深堆稳定同时依赖「接触点回收」（跨帧
稳定 ID + 大预测距离），即 T1 的「接触 ID 跨帧匹配」项。** 软接触改动已
`git stash`（stash@{0}）等候与该件一起落地，不单独合入（避免净退步进主干）。

**下一段施工顺序**：① 窄相接触特征 ID（clip 面/棱特征命名 + 跨帧 ID 匹配
替代近邻匹配）+ 预测距离 0.02；② 按上述配方落地软接触（pop stash 复用）；
③ 金样三场景（col45/pile5/tower25）作验收门。

### 进度更新（2026-09-13 第八段：软接触落地 + 子步配方——塔站住了）

**先纠正上一段的一个误判（重要）**：第七段落地的「skin 0.02 让 5 层堆全睡」
其实是**悬停假象**——硬约束引擎的接触目标 `vn ≥ 0` 使盒子停在各自出生高度
（高度带 [0.25, **2.33**]=出生位、2cm 缝全留），并非沉降入睡；Rapier 是
**沉降到贴合** [0.25, **2.24**]。真正确切的行为需要 speculative 项
（`rhs` 允许一个 tick 内闭合缝）——即软接触形态。

**本轮实测矩阵（金样三场景）**：
1. **软接触（erp/cfm 配方）+ feature ID + skin 0.02，substeps=1 / iters=16**：
   pile5 **几何沉降正确**（[0.25,2.25] ≈ Rapier 的 2.24）但残留 0.3 m/s
   极限环（不入睡）；由 iters=64 可消除 → 是每迭代传播效率而非公式错误；
   tower25 仍崩。
2. **substeps=4 子步**（small-steps）：tower25 初始扰动骤降（KE 20k→0.8-3 kJ）、
   崩溃从 t≈100 延后至 t≈300-400（iters 4/8）；**iters=16 时塔 600 tick
   塔身完整**（|v| 0.26→0.47 缓慢蠕动、无坍塌；band [0.25,12.24] 全域保持）。
3. **子步配方（substeps=4 / iters=16）一个配方治好两个**：
   - **pile5：t≤200 全睡 2000/2000、|v|=0、几何 [0.25,2.25]（≈Rapier）**；
   - **tower25：600 tick 塔身完整**（残留 |v|≈0.4 蠕动未入睡——与 Rapier
     t=100 入睡仍有差距，差距 = 每迭代传播效率；我们靠 4× 子步补上）。
4. m0_gates：PASS（门槛 p50 **0.522 ms**；压力场景末态深穿透 **0**、
   最大深度 0.101）。

**落地**：软接触求解器 + feature ID + skin 0.02 已合入（本段提交）。
**深堆配方入档**：`substeps=4`（默认保持 1 控成本；M1 验收跑轮按配方执行

   只对了一半**：填充确实是单段最大项（18.7%），但 `sat + clip = 47.4%` 才是
   主体；专用路径可去掉 `fill + poly_for = 24.2%`，不是「一步到 25ms」的钥匙。
2. **负面结果（记档）**：早先「禁用填充缓存（`if … || true`）后窄相不变」的实验
   是**误导**的——8 线程下每块 clone 的缓存本就冷启动、且两次运行的相位窗口不同，
   差值落在噪声里；纳秒精度 + 串行 + 同窗口复测后，填充成本稳定可见（31.6ms/帧）。
   教训：分相量测必须（a）串行路径、（b）纳秒累加（`as_micros()` 对亚微秒值截断，
   会把绝大部分样本记成 0）、（c）相位对齐的同窗口对比。
3. **修订后的 T3 剩余路径（按预期收益排序）**：
   - ① 盒对专用路径：跳过 `poly_for` + `fill`，由 `(pos, rot, half)` 直接生成轴
     （3 次旋转/体）与参考/入射面 4 点 ⇒ 预期 −24%；
   - ② `clip` 侧面平面**去掉 `normalize()`**：`da<=0` / `da*db<0` / `t=da/(da−db)`
     与朝向判定全部与平面向量尺度无关 ⇒ 每 clip 省 4 次 `sqrt`+除法；
   - ③ `sat`：轴表可直接由 ±u 轴生成（当前快路径仍读 `poly.face_normal[0/2/4]`），
     减少数组访存；`obb_separated` 已算过的 6 次轴旋转在同一对内被重复计算，可复用；
   - ④ 若要压到 25ms 以下，仅靠 ①②③（估算 −30%~−35% → 峰值 ~32-35ms）不够，
     还需结构级改动（按体缓存轴/面、或 pair 批处理）；**如实标注：验收仍未达**。

### 进度更新（2026-09-13 第十九段：T3 盒对专用路径落地——峰 −30%，仍未达 25ms）

按第十八段的量测结论实现 ①②③：

1. **盒对专用路径**（`(Shape::Box, Shape::Box)` 独立分支）：轴由 `(rot, half)`
   直生（每体 3 次旋转），与预筛**共用**（`obb_separated` 改为返回

**第十九段末：缺口归属分析（先算账再动手，避免又一轮猜测）**

与分支**（每对触及两个体的散列数据：shape/pose/rot 数组 20 万条；外加 15k
流形输出 ≈1.5MB/帧）。

据此逐项算过两个「看起来大」的候选，结论是**都不值得做**（记录以免重走）：

| 候选 | 理论收益推算 | 结论 |
|---|---|---|
| 按体缓存轴/面 | 每对 6 次旋转 → 每体 3 次：省 800k 旋转/帧 ≈ 5-10ms 单核 ≈ **1ms@8线程**；另加 7.2MB/帧数组与共享只读改造 | 收益/复杂度不划算，暂不做 |
| 并行开销（每块 clone 结构 + 结果拼接） | 8 块 × ~10 Vec + HashMap ≈ 100 次分配/帧，单核 ~0.3-1ms ≈ **0.1ms@8线程** | 不是缺口来源 |
| 并行效率 | 实测 8 线程峰值 31.56ms vs 单核 ~200ms/帧 ⇒ 加速比 **6.3×**（理想 8×）——缺口 ~20%，与访存带宽饱和一致 | 归入局部性问题 |

**结论（写入计划，供下一步直接执行）**：剩余 6.6ms 属**局部性/带宽型缺口**，
要靠结构改动而非删冗余：① pair 按体分组处理（同一体的数据一次载入、连续消费

拷贝）；③ 与 T4「小岛批」合并考虑——4 路 SIMD 批处理天然要求把体数据先聚到

两次「先算账」都证明：删冗余有效（−11%），凭直觉的微优化收益在噪声里）。

**结构性问题（必须记档，影响「8B 最低档」的判定口径）**：8B 单 tick ≈254ms 中

  「10 万个小岛」故岛级并行已吃满（5.5×/8 线程，剩余是负载不均与串行段）；
- **无 SIMD**（`forbid(unsafe_code)` + `std::simd` 未稳定）⇒ 向量化窄相/解算不可用；
- ⇒ 在 M1 的约束集内，8B 档的 tick 时长**结构性**由「22.5 万流形 × 16 迭代 ×
  inner 4」的合法工作量决定，**「≥30 FPS」在 M1 内不可达**。
