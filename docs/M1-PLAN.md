## 2. 首段已落地

- **宽相速度自适应 fat 边距**（`crates/vxl-phys-broad`）：`fat_margin_for = base +
  |v_lin|·dt·1.5`（钳 0.25m）；`BroadPhase::set_step(dt)` 注入步长；
  `DynamicBvh::move_proxy_scaled`/`insert_fat`。效果：树更新 **55–70ms → 1.2ms**
  （快体不再每帧 remove+insert，树形稳定）。确定性保持（纯函数、时序无关；
  输出对仍是精确重叠对，扫描结果未变）。
- `m1_scale` 诊断补窄相列（本文测量的依据）。

## 3. 剩余任务（按杠杆排序，含验收判据）

### T1 求解器稳定性（万级堆叠稳定；对靶：压力堆从不入睡 + deep 7）
- TGS-Soft 软约束（Box2D v3 谱系：soft bias/等效柔度）替代纯 Baumgarte 位置偏置；
- 接触 ID 跨帧匹配（warm 起点从「距离近邻匹配」升级为「特征 ID 匹配」），
  warm 命中率入诊断；
- **验收**：压力堆 600 tick 内 `awake → 0`、`deep = 0`、入睡后 p50 → ≈0。

### T2 宽相重建尖峰 + 查询回涨
- 重建尖峰（47–54ms，每 3–5 tick 一次）：预算化重插（每帧上限）/ 部分重建；
- 查询 30–42ms：fat 盒压缩（速度边距只在「无接触」体上放大；或量化节点 8B/child）；
- **验收**：8B 沉降期任一 tick 宽相 ≤15ms（树 ≤5ms）。

### T3 窄相专用快路径（≈55ms/帧）
- 盒-盒 SAT + 4 点裁剪专用路径（体素场景 90% pair）；pair 按 shape 类型分批；
- **内边去除**（高度场/网格内边不产生假接触；宿主客户幽灵卡顿硬需求）；
- **验收**：窄相 ≤25ms（8B 沉降峰值）；内边/幽灵接触专项测试过。

### T4 求解并行（大岛）
- 现实约束：核心 `#![forbid(unsafe_code)]`——**大岛内并行需 unsafe 分域**，属
  V2 §5 的 M4+ 自定义池条款，M1 不做（与 Rapier 同级：岛级并行 + 小岛批）；
- M1 路径：小岛（≤8 体）4/8 向量化批（V2 §4.3）；
- **验收**：多小岛场景（碎片雨）并行扩展 ≥3×/8 线程；与串行 bit 级一致保持。

### T5 金样对照（Rapier）
- `rapier3d` dev-dependency + 同场景（单塔/金字塔/斜坡投入）逐帧位姿对照；
- 容差表入档（建议：位置 1e-2、速度 5e-2、入睡时点 ±3 tick）；
- **验收**：三场景容差内 + CI job（金样 job 独立）。

### T6 8A 碰撞行
- 10 × 1200 格复合体 + 世界：碰撞管线（宽+窄）计时；
- **验收**：T0 档 ≤1.5ms CPU（CI 产物报告；本机数字注明环境差异）。

## 4. 执行纪律（继承 M0）

四门禁 = 提交门（miri/loom/TSan/ASan + 三编译器 + aarch64 哈希比对，CI 已就位）；
严格 f32 / 禁 fast-math / 有序归约；`forbid(unsafe_code)`（unsafe 需 SAFETY 注释 +
loom/miri 门 + 用户批准）；承重墙禁令（rayon 默认路径保持全绿）；里程碑独立价值
（任一任务不过即停在上一个可用状态）；录像令（每步命令 + 原始输出进提交说明）。
