## 2. 首段已落地

- **宽相速度自适应 fat 边距**（`crates/vxl-phys-broad`）：`fat_margin_for = base +
  |v_lin|·dt·1.5`（钳 0.25m）；`BroadPhase::set_step(dt)` 注入步长；
  `DynamicBvh::move_proxy_scaled`/`insert_fat`。效果：树更新 **55–70ms → 1.2ms**
  （快体不再每帧 remove+insert，树形稳定）。确定性保持（纯函数、时序无关；
  输出对仍是精确重叠对，扫描结果未变）。
- `m1_scale` 诊断补窄相列（本文测量的依据）。

## 3. 剩余任务（按杠杆排序，含验收判据）

### 进度更新（2026-09-12 第二段）

已落地两件 + 一个存量缺陷的证据链：

1. **求解器分组切分 bug 修复**（`solve_island`）：`岛数 < 线程组数` 时旧式
   `g·ceil(n/g)` 产出 `start > n` 的越界区间（9 岛 8 组实测 panic）——改为比例
   切分（`g·n/g_count`），尾组空区间合法。新跑轮 `m1_pile` 首跑即抓出。
2. **分裂冲量（split impulse）落地**：位置修正（Baumgarte 语义）从速度通道
   移入独立偏置通道（`bias_target`/`pbias` + 每体偏置速度 scratch），偏置速度
   仅按 `dt` 写回位置、绝不进入真实速度。实测：8B 规模沉降累计均值
   91.9 → **78.6ms**（较 M0 基线 −24%）；门槛场景复验 PASS；40 测试目标全绿。
3. **存量稳定性缺陷（重要发现，未解决）**：留缝密堆（间距 0.52 = 2cm 缝）
   持续「沸腾」：5 层堆 200 tick 后 |v|max 3–6 m/s（应 ≈0，睡眠阈 0.04）；
   25 层堆渐进修至 |v|max 78–85 m/s（能量持续注入）。**已排除**：
   —— 与本次宽相/求解改动无关（旧求解器同轨迹复现：46→62→78 m/s）；
   —— 与 Baumgarte 泵能无直接关系（分裂冲量后轨迹同量级）；
   —— 与堆高收敛无关（5 层即沸腾；贴合堆（间距 0.5）的 pyramid 测试能入睡 ✓）。
   **定位工具**：`examples/diag_pile.rs`（点火 tick、|v|max、接触深度直方图
   >0.02/>0.1/>0.25、流形数）；`examples/m1_pile.rs`（M1 稳定门槛跑轮）。
   **下一步嫌疑单**（按可能性）：① 简单盒-盒对的脉冲-能量守恒单测
   （单盒落单盒、双盒斜靠：数值<0.01 残差）；② 窄相盒-盒流形在“刚接触-浅
   穿透-滑动”区间的法线/深度正确性（对拍解析解）；③ warm 起点在流形点集
   变化时的匹配唯一性（同一 warm 点不得配多个新点）；④ 摩擦锥 clamp 的
   能量守恒性（切向冲量功率 ≤ 0）。

## 4. 执行纪律（继承 M0）

四门禁 = 提交门（miri/loom/TSan/ASan + 三编译器 + aarch64 哈希比对，CI 已就位）；
严格 f32 / 禁 fast-math / 有序归约；`forbid(unsafe_code)`（unsafe 需 SAFETY 注释 +
loom/miri 门 + 用户批准）；承重墙禁令（rayon 默认路径保持全绿）；里程碑独立价值
（任一任务不过即停在上一个可用状态）；录像令（每步命令 + 原始输出进提交说明）。
