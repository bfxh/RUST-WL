## 1. 落地了什么（一句话）

**体↔流体的动量交换通了**：体表面生成 Akinci 两层边界粒子（与流体粒子**同数组、同核、同式**，
只是运动学冻结），流体把反作用（**力 + 绕体原点的力矩**）还回体；
`add_fluid_with_boundary_coupling` 是**显式选择档**，默认关 ⇒ 既有场景四哈希逐位不变。

## 3. 关键设计决定（写给下一个会话，别重新发明）

1. **边界粒子 = 冻结流体粒子**（SPEC §4.8 指定的最小变体）：进同一套数组/核/压力，
   只是不积分、每 tick 由门面按体重建、速度取**体面速度** `v + ω×r`。
   ⇒ 反作用天然是**同一对的反对称**（`force_pass` 里对 `j ≥ n_fluid` 的邻居累加 `−F_i`），
   不发明新公式。
2. **包络体积 `V_b = s³`、两层在 0.5s / 1.5s**：不是拍的档——既有壁邻补偿（镜像鬼影）把静置
   晶格的前两层镜像补回核内质量，`h = 2s` 时**恰两层**落在核半径内；层位取整数半格。
3. **薄体层深钳制**（`d_k = min((k+0.5)·s, (0.45+0.45k)·half_min)`）：不钳制时，某向半厚 < 1.5s 的
   体会让两侧内移层**穿过体心互穿** ⇒ 边界粒子互相供密度 ⇒ ρ_b 虚高 ⇒ 假力（实测 0.12 m 盒：
   侧向 51 N、浮力 5.9×ρVg）。钳制是**几何约束**不是新物理式；厚体（≥1.5s）钳制不生效。
4. **边界粒子只从流体取密度**（不吃边界-边界对）：这是 Akinci「边界压力 = 外推的流体压力」的口径，
   同时让"薄体互穿"在 ρ_b 侧也失效（互穿不再造压）。
5. **承压 / 动量交换分工**（写死在 `Tank` 门与测试注里）：**围水是提供者通道的活**
   （`contacts_point_boundary` + 投影）；2b 只管**体↔流体的动量交换**。别让 2b 兼职围水，见 §4。
6. **2a 二选一**：覆盖集（本 tick 进了边界粒子集的体）里的体，2a 的浮力/阻力**让位**；
   形状不受支持或不在近域的体仍走 2a 粗档 ⇒ 既不叠加、也不留空。

## 4. 否证与适用边界（**别重走**）

- ❌ **"两层边界粒子可以替代提供者围水"** —— 实测否证。只用边界粒子搭盆（0.5 盆腔、h=0.1、
  板 + 四堰）：底面只承到水重的 **47%**，水从角/缝漏光（vmax 顶到 CFL 钳制线、粒子自由落体到 y≈−10）。
  机理：全潜体（或水柱）能否被压力承住，取决于**密度超出 ρ0 的斜率**（静水所需的 +5% 量级），
  而固定两层能提供的补偿在**沉降 1–1.5 cm 后就饱和**——越过第一层就再无上升支。
  ⇒ 围水继续由提供者投影负责（真实场景本来如此：槽是体素提供者）。
- ❌ **"给边界侧压强上闸能治重体被推飞"** —— 试过、无效、已回退：把边界对的 `cj2` 钳到 `ci2`
  （Akinci 插值性质）后，ρ2000 盒照样被抛（尖峰来自**流体侧** ρ_i 的 q⁷ 放大，不是边界侧）。
  记录在此，免得下一个人重试。
  ⚠️ 顺带教训：那条闸第一次写成了对**所有邻居**生效 ⇒ 削平了流体自身的压强不对称性，
  **改了冻结行为**（2a 示例读数从 1.215 变 1.172 才发现）。任何"闸/钳"都必须**只对边界对**生效。
- ⚠️ **适用边界：体特征尺寸 ≲ 2h 时反作用失准**（h=0.1 ⇒ ≲ 0.2 m）。本仓默认档的 0.12 m 盒（1.2h）：
  浮力 1.5–1.65×ρVg、**侧向假力 0.6×（debug）～2.1×（release）ρVg**；**重体（≳1.6ρ0）会被离散
  挤压尖峰推飞**（实测 ρ2000：|v| 6.4 m/s、|ω| 37 rad/s、末态掉出世界）；ρ1200 该沉不沉。
  ⇒ 2b 保持**选择档（默认关）**，`fluid_buoyancy 2b` 的判定表把重体显式标 ⚠️ 而不是藏进"沉/浮"。
  这与既有提供者方案的**已接受偏差同族**（`PLAN-0.3.md` §4.3：底压 ≈1.65× 静水，镜像鬼影 q⁷ 密度尾）
  ——不是 2b 独有，也不是量纲错；升级路径见 `OPEN-PROBLEMS.md`（P7）。
- ⚠️ **初值不许重叠**：体**不能直接落在已有水格上**（边界粒子与流体粒子近同位 ⇒ ρ 爆 ⇒ CFL
  尖峰）。干净开局三选一：水格按体几何挖空（铸装）／体从水面上方落入／体放在干区。
  本文件的门与示例取"从上方落入"。**这条也改了判据的写法**：入水柱峰值差的量级在于
  "体有没有被托住"，而"体前方一层平均 vx"会被体自身的强阻尼（20 tick 只走 0.029 m）与残波淹没。
- ⚠️ **debug/release 的浮点路径差会改判据**：同一个"扫掠推水"判据在 debug 读 +0.97 m/s、
  在 release 读 **−0.41 m/s**（都过了 `m0_gates`——引擎哈希门只锁 release）。⇒ 耦合门的阈值要
  **取比值/量级差**，不要卡窄带；CI 跑的是 `--release`，两边都得过。
