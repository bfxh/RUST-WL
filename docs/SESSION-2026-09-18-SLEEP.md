## 1. 三项实测（全文见 `EXPERIMENTS.md` 末节）

**A. Rapier 睡眠判据（源码核实）**：`normalized_linear_threshold` 默认 **0.05**（社区口径的
0.4 是错的），比的是**最远点速度** `|v|+|ω|·extent` **外加位置位移率**；角速度对带碰撞体者
被折进前者。⇒ 塔的点速度 ≈0.31 ≫ 0.05，**Rapier 也不会让它睡** ⇒ **判据对齐不是解药**
（这条否掉了本轮开工时的主假设）。

**B. 证伪「残余 = 去穿透偏置速度」**：`max_corrective_velocity` 下扫（它钳的就是
`erp_inv_dt·pen`）：3.0/0.5/0.2 **逐位相同**（钳位从未生效）；0.1 变了但无改善；
0.05 穿透涨 3×、0.02 塔被搞垮。⇒ 残余不是这个偏置速度。
（旁证：早前探针记的 0.24 m/s 与塔 \|v\| 0.22 同量是**巧合**。）

**C. 正向发现：残余由子步分辨率决定**。tower25 同配方只改 `substeps`：
\|v\|max 0.29/0.16/0.17、KE 900/301/109、**阈值下可睡体 294/1112/2080（共 2500）**
（4/8/16 子步）。等扫掠对照（都 512 扫掠）：子步轴 1112 可睡体 vs 迭代轴 709 ⇒
**两条轴都有效、子步轴更省**。机理：残余主项 = 每子步扰动余量（`g·sub_dt` + 重新线性化
间断），随 `sub_dt` 缩小。

## 2. 现状与判据

- 睡眠缺口 = **真实残余蠕动差**（点速度我们 ~0.31 / Rapier ~0.05，6×），与 §6/§7 的
  "稳定性/工作量比"缺口是**同一件事的两面**（性能面 9–10×、保真面 6×）。
- **塔不是整体沸腾，是少数尾部体卡住全岛**：子步 16 时 2080/2500 已满足入睡阈值，
  但本仓是**岛级原子入睡** ⇒ 一个岛里只要有体没静，全岛不睡（Rapier 允许岛内子块入睡）。
- 保真档（不改默认）：金样加 `substeps=8/16` 可显著改善 T5 速度列与可睡体数，成本 2×/4×；
  **默认档不换**（8B 侧回归不可接受）。

## 4. 落地：无偏置末趟（Rapier 「带偏置趟 → 位置积分 → 无偏置趟」）

§3 的入口 1 本轮**已做**（`PhysConfig::stabilization_iterations`，**默认 0 = 关闭**
⇒ 三哈希逐位不变；`World::substep` 在位置积分后调用 `solve_unbiased`）。取舍型结果：

| 判据 | 结果 |
|---|---|
| pile5 | **1735 → 1960/2000 入睡**、KE ~10 → 1.6、最深 0.005 ⇒ 大改善 |
| col45 | 45/45 → **45/45** ⇒ 中性（未踩历史退档坑） |
| tower25 | KE 905 → 650、最深 0.017 → **0.009**、\|v\| 0.305 → 0.191 ⇒ 改善，仍 0 入睡 |
| 125 体（T1 主靶） | 末态 KE 1.6 → **18.1** ⇒ **退化** |
| 与子步叠加 | `sub8+stab2` ⇒ \|v\|max 0.119、KE 174、阈值下 1411（基线 294）⇒ **增益可乘** |
| 能否替代迭代数 | **否**：`iters4+stab2` 崩（\|v\| 2.31）、`iters8+stab4` 退步 ⇒ 缺口不变 |

**忠实性教训（已修）**：第一版把切向漂移回拉也归零了——**Rapier 的无偏置趟是保留它的**
（切向 `rhs_wo_bias = tangent_velocity`）。归零使 125 体场景 \|ω\| 0.13→0.45。
⇒ 读源码时"哪些项属于 bias"要逐项核，别按直觉归零。

**处置**：与 `DRIFT_BIAS_SCALE = 0` 同类——**默认关、按需开、消融留档**；
当前最佳保真档 = 金样配方 `... 16 0.01 4 3.0 30 8 2`。**下一个单行变体（未试）**：
无偏置趟改 Rapier 的 `cfm_factor = 1.0`（刚性）——本实现沿用软 cfm，这可能是 125 体
退化的成因，但它会动到"软接触限制迭代增益"的金样定标结论，须同表复核。
