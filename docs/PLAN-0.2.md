# 限制清除计划（PLAN-0.2）

> 2026-09-14 立。来源：上一轮交付时如实列出的四条限制。**口径：先文档、后开工；
> 每条都必须「做法 + 验证 + 实测数字」三件套齐全才算关闭；不得用「应该更快」结账。**
> 纪律不变：**性能类改动优先走「逐位安全」路线**（同表达式、同求值顺序，只是少算
> 冗余次数）——四哈希基线必须逐位不变；若改动必然改数（如求解顺序），单列「重定标
> 轨道」，先出方案与代价，不擅自改契约。

## L1 — 外壳 × 高度场不受理

- **现状**：`hull_pair` 对 `Shape::HeightField` 返回（`support_of` 给 `None`）⇒ 外壳落
  在高度场上无接触、直接穿地。
- **做法**：顶点采样，与「外壳 × 提供者」同构 —— 外壳世界顶点逐个查
  `HeightField::sample(x, z) -> (h, n)`；`vertex.y < h + band` 记接触
  （depth = h − y，法线取地形法线）；多数派法线 + 取最深 ≤4 点成流形。
  越出高度场范围 = 无接触（`sample` 返回 `None`）。
- **口径**：法线约定沿用高度场既有路径（hf 在 a ⇒ +n_t，在 b ⇒ −n_t）。
- **验证**：门面测试「外壳静置高度场」（复刻盒版用例，静置 y 带 + 入睡 + health）；
  既有 `box_falls_and_rests_on_heightfield` 逐位不变。
- **预期**：功能补齐；成本 = 顶点数 × 一次列采样（与盒版同量级）。

## L2 — 外壳支撑体每对重建（未做缓存）

- **现状**：`support_of` 每对现构 `HullSupport`（含 `Mat3::from_quat`）；EPA 后的流形
  细化与外层顶点采样各自把**全部点云**做一次世界变换 ⇒ 一个外壳体同帧多对时重复 O(n)。
- **做法**：窄相加「外壳世界点缓存」：`(body, pose 指纹) -> Vec<Vec3>`（世界点）。
  指纹沿用既有 `cached_a/cached_b` 同款（体号 + 量化姿态）；命中即复用。
  旋转矩阵也从既有的体轴缓存取（同帧同体只算一次）。
- **验证**：缓存版与直算版**逐位一致**（同一表达式 ⇒ 可断言相等）；门面外壳测试不变。
- **预期**：外壳体每帧多接触对时省掉 (对数−1)×O(n) 变换；单对场景无变化（不为负）。

## L3 — 喷溅场无加速结构

- **现状**：`density_grad` 每次 O(#核) 全扫（3σ 截断只省了指数运算，省不掉遍历）。
- **做法**：**均匀网格**（密集 `Vec<Vec<u32>>`，格边长 = 全场 max(3σ)，按注册序登记、
  不做 HashMap ⇒ 确定性）。查询只遍历 p 所在格的登记表（按构造，凡能影响 p 的核必
  登记在该格）。
- **关键**：查询时把候选**按注册序升序累加** ⇒ 与全扫版**逐位一致**（浮点求和顺序
  相同）。这是本条的验收主判据：`grid == brute` 用 `assert_eq!`（不是 epsilon）。
- **开关**：`#核 < 阈值`（如 64）不建网格（小场全扫更快，也避免小场构表开销）。
- **验证**：`grid_vs_brute_is_bitwise`（随机化但确定性的点集与查询点）；
  既有 5 测试不变；门面喷溅测试不变。
- **预期**：76 核演示场无感（本就便宜）；上万核时从 O(N) 降到 O(局部密度)，为
  「喷溅体量上量」开路。

## L4 — 10 万体 @30 FPS 不可达（结构性 ~10× 差距）

**现状（本轮复核）**：`m0_gates` 压测（100×100×25 = 10001 动态盒、全接触**单岛**）
p50 ≈ **305 ms**；分解（DESIGN-staged-solver §7–§11）：求解 ≈ 89% tick、迭代环 ≈ 95% 求解。

**已做**（清单，防重复劳动）：岛间并行（gather→solve→scatter，逐位）；宽相边距 K=6；
warm 槽表；固定数组接触点；窄相分块并行。

**本轮新增定位（逐位安全，先做）**：

1. **`apply_world_inv_inertia` 每调用一次 `Mat3::from_quat`**（`body.rs:172`）——
   迭代环内被调用 `点数×2侧×迭代数×接触数` 次（压测量级 ≈ 千万次/tick）。
   `from_quat` 是纯函数 ⇒ 按体预计算一次、迭代内复用，**逐位一致**（同 f32 值、
   同后续表达式）。预期：迭代环内省掉全部旋转矩阵重建。
2. **`solve_constraint` 内每迭代重算常量**：`k11/k22 = 1/tmass`、`det/inv`
   （`tmass/cross` 在解算中不变）⇒ 提到迭代外/LICM，**逐位一致**。
3. 复核其余迭代内不变式（`rhs/nmass/cfm/friction` 已预计算 ✓）。

**未做（结构，需重定标 → 单列轨道）**：

- **岛内并行 = 接触图着色分批**（批内体对不相交 ⇒ 可并行/可 SIMD；把「单大岛」
  的墙钟按批并行摊到多核）。**代价**：批序 ≠ 现行严格顺序 ⇒ 数值路径改变 ⇒
  四哈希与金样容差**全部重定标**。方案与验收见本文件 §附录 A。
- **TGS/子步语义**（改数，且已有 staged 证伪记录 —— DESIGN §7–§11）⇒ 不建议复活。

**验收判据（本轮）**：
- 四哈希（m0_gates / stress / determinism / T4 对拍）**逐位不变**；
- `m0_gates` 压测同机同状态复测：p50 相对基线（305 ms）**单调下降**（记录数字，
  不设乐观目标）；若 <5% 收益则如实记为「已排除」；
- 金样（col45/pile5）行为不变。

**如实预期**：本轮（1)(2) 是把「纯冗余」拿掉，量级预计两位数百分比，**不关闭 10×**；
10× 的真正杠杆是岛内并行（附录 A），它必须动数值契约，不能混在「逐位安全」里悄悄做。

## 附录 A：岛内着色并行（重定标轨道，供决策）

1. **做法**：`cbuf` 按「体对不相交」贪心着色（确定性：按约束序、颜色号自增）；
   每次扫掠 = 逐颜色批处理，批内约束写入的体不相交 ⇒ 可 (a) 多线程并行
   （组内再分组 scratch，同现有 gather/scatter 模式）或 (b) 4 路 SIMD 打包。
2. **代价**：批序改变约束处理顺序 ⇒ 不动点不同 ⇒ **数值改变（仍是确定性的）**。
3. **验收（若开工）**：金样三场景容差表重出（col45/pile5 末态 max|Δpos| 不得劣化）；
   125 体 dE ≤20 保持；tower25 |v| 不退化；四哈希**换新基线**并写 ADR 说明；
   压测 p50 目标：核数×有效加速（8 核理想 ≤ 0.2×，实测按批数折损）。
4. **风险**：批间耦合强（深塔每列相邻）⇒ 着色批数少（网格状 ≈ 4–6 色）⇒ 实际
   加速 3–5× 而非核数倍；且「严格 GS 顺序」是现状稳定性的来源之一（此前多轮
   实测），改序需附稳定性回归数据。

### L4 实验记录（压测 10001 动态盒、单岛、p50 基线 305 ms）

- **实验 A（缓存旋转矩阵，64B 行）**：p50 305 → **366 ms**（−20%）；哈希最终回到基线（修 bug 后）。
  **过程 bug（教训）**：gather 里为 `group_lv/av` 清缓冲时**漏清新数组** ⇒ 跨 tick 无限追加、
  索引错位 ⇒ 哈希变化。**哈希判据当场抓住**（这正是「四哈希逐位不变」作为门禁的价值）。
- **实验 B（32B 行：四元数 + inv_mass + 逆惯量）**：p50 305 → **383 ms**（−25%）；哈希一致。
- **归因（数据支持）**：原实现的三次散查（`inv_mass[i]` / `rot(i)` / `local_inv_inertia[i]`）
  按约束序推进 ⇒ **流式、硬件预取友好**；改成 `local_of[i] → gb[q]` 是**依赖加载链**，
  多一跳串行延迟且工作集没降（原数组已在 L3 缓存里）。⇒ **该迭代环内「加 per-body 数组」
  是净负**，此路已排除（两条实验均回退，工作区无残留）。
- **结论**：L4 的杠杆只剩**岛内接触图着色 + 并行/SIMD**（附录 A）——它必然改变求解顺序
  ⇒ 四哈希与金样容差需整体重定标 ⇒ **属独立轨道，不在本轮擅自开工**。

## 追加（同日第二轮）：L4 求解环穷举 + 附录 B 首项落地

### L4 又一个实验（证伪）与穷举结论

- **实验 D（冷热分离）**：`PointConstraint` 188B → 100B（去掉迭代环不用的
  `la/lb/depth0/feature/warm/tmass`，另存 `PointCold`，与 points 同序）。
  实测压测 p50 **295.5 ms（≈ 持平，未达 5% 门槛）** ⇒ 已回退。
  **事后核对**：环内原本只跨 2 条 cache line（冷尾在第三线且本就不被迭代触碰）
  ⇒ 拆了并不减少环内线流量，预测的依据本身错了。
- **穷举结论（四个实验：A 64B 行 / B 32B 行 / C 直取矩阵 / D 冷热分离）**：
  该环**既非算术受限、也非结构体布局受限**；成本在「每点每轮 4 次 lv/av 访问 ×
  点数 × 轮数」本身 ⇒ 逐位安全的微优化已穷尽（唯一曾测到 −2.5% 的切向预计算，
  在机器状态漂移 ±3% 下无法与噪声区分，按纪律一并回退，工作区不留未证实改动）。
- ⇒ **10× 只能来自算法面**：① 减少点数/轮数（改数值）；② 岛内接触图着色并行
  （改数值 + 并行开销，见附录 A）；③ 睡眠面（P1 staged 语义，改数值）。
  三者都要重定标四哈希与金样容差 ⇒ 属需要拍板的独立轨道。

### 附录 B 首项落地：喷溅场 × 介质耦合（`MediumField`）

- `GaussianSplatField` 实现 `MediumField`：`sample` 给「密度 ∝ σ、流速 = 场流速、
  黏性 ∝ σ、占用率 = σ/iso」，`medium_density = 0` 时零成本短路（返回真空）；
  `deposit` 明确为**单向耦合**（静态场不响应，双向见 ROUTE §3.1 待办）。
- 门面新增 `medium_pass`（力场之后、速度积分之前）：对每个动体 × 每个介质场，
  累加二次阻力 `F = −½·ρ·Cd·A·|v_rel|·v_rel`；迎风面积按形状估（盒/外壳用三对面
  均值、球用 πr²）。确定性：场按 id、体按索引，无浮点归约顺序问题。
- 实测（新测试）：同一场景仅差 `medium_density` —— 自由落体 y=−2.16 / v=−14.7 vs
  介质中 y=+7.12 / v=−1.21（终端速度 ≈1.3 m/s，与 ρ≈7 kg/m³、A=0.36 m² 物理自洽）。
- 四哈希逐位不变（无介质场时该阶段零成本短路）；43 测试目标全绿；clippy 零警告。

## 追加（2026-09-15 第三轮）：附录 B 首项落地 —— trimesh 提供者（网格域闭合）

- **`vxl-phys-terrain/src/mesh.rs` 新增 `TriMesh`**（任意三角网，ROUTE 域表「网格」行关闭）：
  - **薄壳语义**：`depth = skin − 到最近三角形距离`，法线 = 面法线，**不做内外判定**
    （与体素/喷溅的实体语义互补，适合薄板/地形片）。
  - **最近点查询**：Ericson《Real-Time Collision Detection》闭式解；建表后 3×3×3
    邻域（三角形按 AABB 登记覆盖格），未建表回退全扫。
  - **加速结构选型**：均匀网格而非 BVH —— 三角网多为静态，建表一次 O(三角形数)，
    查询 O(邻域)；BVH 对薄壳邻域查询无显著优势且增删复杂。格边 = 平均边长（下限
    0.5，`GRID_MAX_BINS` 封顶）；**精度前提：`skin < 格边/2`**（文档化）。
