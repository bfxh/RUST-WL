     ⇒ ① **角向消除在位置级下依然成立**（角向 **1** vs 基线 261）⇒ 再次确认"速度级**命令**
     一个非零滑动"才是自转的来源；② **但位置级没把蠕动控制买回来**：0.05 时 Δpos
     **0.1276 > 基线 0.0863**，而把强度提到能起作用（1.0）就**发散** ⇒ **该形态否证**。
     ③ **诊断（两条，都是结构性的）**：
        (a) **无界投影 + 逐流形累加**——一个体有 ~8 个接触 ⇒ 每子步被平移 ~8 次
        （1.0 时可达 ~8 cm/子步，而 sub_dt ≈ 1 ms）⇒ 求解器对剧烈几何变化的反应本身就是注能；
        (b) **投影分不清"数值漂移"与"真实滑移"**——滑动接触的锚点分离**就是**真实相对运动，
        把体**传送**回去等于抹掉真实滑移；Rapier 那套是**受接触软度/最大修正量约束**的位置修正，
        **不是无条件传送**。
     ⇒ **正确形态＝摩擦/软度受限的相互投影**：每子步每体总位移要有上限（与 `max_corr`/slop
     同量级）、按**摩擦锥可交付量**限幅，且**先与速度级并存**（不是替换）再看能否同时保住
     Δpos 与角向。
     ✅ 顺带：默认关的路径**实测逐位中性**（`m0_gates` 哈希 `0x6219d186…` 不变、末态活跃 51、
     PASS）——"对既有场景逐位中性必须实测"的又一次执行。
   - ✅ **放置点是关键变量（同日，单变量）**：**同一份修正、同一强度（1.0），只改放置位置**：

     | 放置 | 稳定性 | 仅角速超阈 | 仅线性超阈 | Δpos |

     | 岛求解**之后**（写回/剪枝后） | **稳** | **3** | 678 | 0.1148 |
     | 基线（速度级 1.0） | 稳 | 261 | 191 | 0.0863 |

     （均塔 600 tick、速度级关闭以隔离位置级。）
     ⇒ ① **"先推位置再解"是发散的直接原因**——等于把剧烈变化的几何喂给求解器，它对变化的
     反应本身就是注能；放到**求解之后**（冲量已施加）就稳了 ⇒ **位置级修正必须放在求解之后**
     （与 Rapier "位置积分在速度解之后"一致）。
     ② **逐流形累加的问题转成了线性残差**：角向被清掉（**3** vs 261）而线性反而变差
     （678 vs 191），Δpos 仍不如基线（0.1148 vs 0.0863）⇒ 与诊断 (a) 吻合：一个体 ~8 个接触
     ⇒ 每子步被推 ~8 次、方向不一致 ⇒ **净平移**。

   - **落脚点**：`World::substep()` 中 `Integrator::integrate_positions`

  ⑭ 🎯 **根因定位（2026-09-21，纯读码 + 已有数据）：`sd` 是投影量 + 桶剪枝半径太小 ⇒ 自锁**

     > ⚠️ **此"根因"的支撑读数已被 ⑱ 否证**（球没有自锁，只是在滚）。下面这段读码分析作为
     > **"`sd` 是投影量、剪枝用 AABB"这一事实描述**仍然成立，但**不能再当作已观测缺陷的解释**；
     > 是否真有自锁形态，需另立可判别探针（⑱ 的 clearance 口径）在**人为把体放进网格内部**时复验。

     `vxl-phys-terrain/src/mesh.rs` 的球查询：
     ```rust
     let Some((_, q, n, ti)) = self.closest(center, radius + skin) else { return true };
     let sd = (center - q).dot(n);      // ← **投影量**：不是到最近点的距离
     let depth = radius - sd;           // 远三角形只要 (center−q) 近似垂直于 n，sd 就小 ⇒ depth≈0
     if depth < -skin { return true; }
     ```
     两条合起来构成闭环：
     1. **`sd` 是投影量** ⇒ 一条**远处**的三角形只要几何"擦着"，就能给出 `depth ≈ 0` 的**有效接触**；
     2. **桶剪枝**（`closest` 内"桶 AABB 距查询点 > `max_d` ⇒ 整桶跳过"）用的
        `max_d = radius + skin`（≈0.22 m）；而**体陷在地表之下时，真正托着它的那张三角形
        所在桶与其 AABB 相距约 1 m ≫ max_d ⇒ 被剪掉** ⇒ 候选里只剩"擦着"的远三角形。
     ⇒ **幽灵支撑**：球被一条远方的接触按住，停在地表下 1.09 m 且**永不被顶出**（自锁）。
     ⇒ 这同时解释了 P5 最初那个症状（体陷进三角网后不再回来）。

     ⚠️ **且该剪枝的"语义等价"论证是错的**（代码注释原文）：
     "两个调用方（点/球）本就丢弃 `depth < −skin`（等价 `dist > max_d`）" ——
     但调用方丢弃用的是 **`sd`（投影量）**，**不是 `dist`**；两者只在"q 是垂足"时等价，
     而**恰恰在"体陷在网格里"时不等价** ⇒ 剪枝会把唯一能救它的那张面剪掉。

     **修法方向（须单独立项 + 逐位门禁）**：凡"体可能陷在网格内"的查询，
     剪枝/接受都必须**以距离为界**（例如同时要求 `|center − q| ≤ radius + skin`，
     或把深度改用**平面距离**并另加距离上界）；仅靠 `sd` 判据在几何上是**不健全的**
     （远处擦着的三角形可任意给出小 `sd`）。
