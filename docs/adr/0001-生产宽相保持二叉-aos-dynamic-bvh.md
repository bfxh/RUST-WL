# ADR 0001：生产宽相保持二叉 AoS DynamicBvh；宽节点树不接线

- 状态：**accepted**（2026-09-14）
- 取代：无；被取代：无

## 背景（Context）

M1 验收要求 8B 沉降期宽相峰 ≤15ms（树 ≤5ms）。实测基线：宽相均 12.94ms 达标，
**峰 33.95ms**（树峰 6.86 + 查询峰 25.57，查询峰 = 缓存翻转帧全量重查）。
为压峰先后实现并接入了两版宽节点树，均为「孤立对拍全胜、生产接入净负」：

- `wide::WideBvh`（8 路宽叶 ≤8 体）：树峰 −58%（7.30→3.10，达树验收），
  但候选总数 5.9×（35.4 万→207.8 万），查询均 +90%，宽相合计净亏 6.4ms/帧。
- `bvh8.rs`（8 盒连续宽内部 260B + 窄叶 1–2 体）：隔离对拍探针边距 −33%..−45%，
  生产接入 broad 合计 10.5→11.9ms（叶容 1 档），仍净负。

机制已定量：**生产查询相位里缓存命中体不遍历，只对旧候选表做精确过滤，
代价 ≈32ns/条**（隔离对拍 ≈4ns，因生产 `aabbs` 是 4.8MB 冷数组）。宽节点把
候选粒度放大 1.2–2.4×，遍历省下的时间抵不过过滤开销。查询瓶颈是**候选量与
候选过滤的访存局部性**，不是遍历层数。

## 决定（Decision）

我们将继续以二叉 AoS `DynamicBvh` 作为生产宽相树，不对宽节点树接线。
`wide.rs`（21 项测试）与 `bvh8.rs`（30 项测试）**保留在 crate 内**作为研究资产
（其中的 B 树溢出传播插入、全叶同深、三树形对拍实验本身是正向资产），但生产
`BvhBroadPhase` 不引用。下一优化杠杆定为「叶盒紧致度 + 候选表/体盒的顺序访问 +
`fix_upwards` 增量路径」，而非树形。

## 后果（Consequences）

- 正面：候选量不再膨胀（这是实测的主导项）；树实现稳定，41 项测试全绿基线保住。
- 负面：树峰 6.86ms 仍超 5ms 验收 1.4×，查询峰 25.57ms 无树形解——T2 峰值缺口
  必须用非树形机制补（见 OPEN-PROBLEMS P2）。
- 保留代码有维护成本（约 1000 行 + 51 项测试不在生产路径上）；其价值 = 树形
  假说已被两版定量证伪，后人不必重做（见 EXPERIMENTS.md 宽相区）。
