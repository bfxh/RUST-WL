# ADR 0003：暖启动匹配策略——特征 ID 主配 + 近邻回退（半径 1×skin）+ 漂移回拉满强度

- 状态：**accepted**（2026-09-14，含首处净正向修订）
- 取代：无；被取代：无

## 背景（Context）

帧间接触点会漂移，暖启动靠「把上一帧的冲量灌给这一帧的对应点」来减少迭代。
配错点（A 点的锚点配给 B 点）会直接注能：错配 ⇒ 帧间「漂移」= 两点真实错位 ⇒
切向目标 `trhs = drift/dt` 成为速度指令 ⇒ 摩擦实现它 ⇒ 注能（机制链自洽，
与 μ=0 全睡、关锥投影 dE +30× 两个独立探针一致）。压力堆不入睡的泵源已定位在
「近邻回退匹配给出的 warm 冲量本身」（关闭回退匹配：125 体复现 dE 峰值
148.9→16.2，−89%）。

但回退暖启动**不能关**：塔的裁剪点每帧漂移、特征匹配常落空，暖启动全靠回退——
零化其暖冲量塔当场崩（|v| 15.6、KE 2.1M）。三场景对回退暖启动的**需求梯度**：
tower > m0_gates ≫ col45/pile5。同时有害匹配与塔需要的匹配**都在 1cm 内**
（半径收紧分不开有害者，零化又伤塔）⇒ 任何纯距离判别式都不可能同时满足三边。

## 决定（Decision）

1. 匹配两级：① 特征 ID 精确匹配（+距离护栏 + 法向夹角 >0.95 才复用）；
   ② 特征未命中走近邻回退，**接受半径从 4×skin 收紧到 1×skin**（即只认
   「确实还是同一材料点」的候选），拒配按新接触处理（重烘焙锚点）。此为本轮
   唯一净正向落地：col45 35/45（+10）、位置 0.0065 更准；pile5 持平；
   tower25 |v| 0.317→0.283、|Δpos| 0.0646→0.0595、塔身完整。
2. 切向漂移回拉（`DRIFT_BIAS_SCALE=1.0`、`DRIFT_DEADZONE=0`）保持满强度无死区：
   它是**承重件**（钳 0.05/0.2 两档都令 m0_gates 门槛 p50 恶化 2.5–5.3×、
   末态不再全睡；关掉则塔弹射）。强度维度不是泵（μ=0 消融已钉死泵在摩擦通道
   的注能，不在回拉强度）。
3. 下一轮判别式必须是**非距离的自适应信号**（候选与验收三边见
   OPEN-PROBLEMS.md P1），在它成立之前不再动全局开关。

## 后果（Consequences）

- 正面：堆族多睡 10 体且位置更准、塔更好；m0_gates 哈希按行为变化更新为
  `0x443778a63faff2c0498a231f4311cbfe`（原 `0xfd70f215…`，已在门禁基线记录）。
- 负面/未解：125 体复现 dE 148.9 **不降**（有害匹配在 1cm 内，半径收不动它）；
  T1 剩余泵未消，pile5 1195/2000 仍未全睡。
- 已探明并回退的相关变体（勿重做）：回退不暖启动（塔崩）、回退点不回拉漂移
  （dE 不降，归因修正）、只零化切向暖冲量（col45 45/45、pile5 1825 但
  m0_gates 末态 0→75）。全部见 EXPERIMENTS.md 解算区。
