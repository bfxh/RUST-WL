# ADR 0005：执行纪律——门禁链五步 + 显式退出码检查

- 状态：**accepted**（2026-09-13 定型；由两次真事故背书）
- 取代：无；被取代：无

## 背景（Context）

两次事故确立了本条：(1) `cargo clippy … | tail -3 && git commit` 的管道**吞掉
退出码**，红灯 clippy 被提交（fb51911 修复）；(2) 第十六段独立审计发现一处
「未验证即提交」的真 bug。根因相同：验证步骤的存在性 ≠ 验证通过，且 shell
组合命令会静默改变语义。

## 决定（Decision）

任何源码改动落地前，门禁链五步**逐一显式**跑完，输出重定向到文件后**显式检查
`$?`**（Git Bash）：

1. `cargo fmt --all`
2. `cargo test --release`（41 项）
3. `cargo clippy --workspace --all-targets -- -D warnings`
4. `bash scripts/vocab_scan.sh .`
5. `/c/vxl-wl-tools/typos.exe .`

外加行为门：m0_gates / determinism / stress / T4 四哈希（ADR 0004）；
涉及求解器数值的改动加金样三场景（RECIPES.md）。**无实测净收益的改动一律回退**
（负面结果记档进 EXPERIMENTS.md，配方留档可重做）。树形/结构类改动先在最小复现
上钉住不变量再动生产代码（fix_upwards 提前退出连续两种补丁都红的教训）。

## 后果（Consequences）

- 正面：自 fb51911 起再未发生红灯提交；回退操作都是安全小步（探针改动均为
  两行级）；EXPERIMENTS.md 的每一条否证都能精确复现。
- 负面：每轮多 5–10 分钟机械开销；「无收益即回退」意味着约 60% 的尝试轮
  不产生代码增量——这是特性不是缺陷（负面结果同样是产出，记入日志）。
