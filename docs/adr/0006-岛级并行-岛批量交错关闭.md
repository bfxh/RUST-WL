# ADR 0006：求解并行架构——岛级并行；岛批量交错路线关闭

- 状态：**accepted**（2026-09-14）
- 取代：无；被取代：无

## 背景（Context）

T4 验收：多小岛场景并行扩展 ≥3×/8 线程 + 末态哈希逐位一致。实现为
`solve_island_group` 岛组并行（岛分组按岛计数均分）。为继续提速曾试三条路：
按工作量（岛内流形数）加权分组、4 岛轮转交错（lane 游标）、约束数据扁平化。
其中交错一度「哈希变了」，需先判定是**语义障碍**还是**实现 bug**。

## 决定（Decision）

1. **岛级并行是 M1 的并行形态**：T4 以 `m1_islands`（12 000 体碎片雨）实测
   **5.08–5.69×/8 线程**、串行/并行末态哈希逐位一致，达标；负载不均假说已证伪
   （加权分组 −1%，噪声；8B 岛分布本就均匀，22.5 万流形/10 万岛 ≈ 2.25/岛）。
2. **岛批量 4-lane 交错路线关闭**：lane 相位耗尽判定错位 bug 修复后（自检
   「lane 步数 17/期望 16」一击命中，修后四哈希逐位回基线 ⇒ 交错**逐位透明**）
   实测仍无收益（解算均 216.6→223.0，−3% 反向）：每步游标分支开销 ≥ ILP/局部性
   收益——访存延迟已被 OOO 在岛内/岛间自行重叠。§7-4「岛批量是解算唯一 SIMD
   入口、估 2–4×」的预期**被证伪**。
3. 岛内并行（同岛约束并行 = Jacobi 化）属行为变化，M1 不做；如日后再上，
   按 ADR 0002 先量化（已量：同岛 4 点 4-lane 净收益 ≤10%）。

## 后果（Consequences）

- 正面：并行问题收敛为「已达标、无结构 bug」（窄相 1→8 线程 ≈3.2×、解算 ≈4.7×
  均为访存受限正常水平，先前「并行度差」是读数误判）；精力可全部投向 T1/T2。
- 负面：解算相位 216.6ms/40tick（8B tick 的 85%）在 M1 结构内**不可再压**
  （固定 23ms + 3.88ms/迭代；唯一大杠杆 = 迭代次数 16→8，属物理取舍非工程优化，
  见 OPEN-PROBLEMS P3）。
- 方法论沉淀：「岛间独立」这类语义判定不必先写 lane 机——颠倒一个既有循环
  （两行）即可分离「语义不成立」与「实现有 bug」，成本差两个数量级。
