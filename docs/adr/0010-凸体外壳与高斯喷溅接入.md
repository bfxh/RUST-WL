# ADR 0010：凸体外壳与高斯喷溅的接入方式

状态：已采纳（2026-09-14）

## 背景

口径要求「不能只是体素，还要多边形、高斯球」，且**不得影响既有性能路径**与确定性。

## 决策

1. **凸体外壳点云存在窄相自持的 `HullStore`**，`Shape::ConvexHull { hull: u32, half }`
   只带 id 与局部 AABB 半长。理由：`Shape` 必须保持 `Copy`（热组/多线程克隆都依赖），
   点云不能内联；`half` 让宽相/惯量/CCD 用同一套公式，**零签名改动**接入窄相。
2. **外壳 × 提供者走顶点采样**（`interop::ProviderColliders::contacts_point`，探针半径
   = 自适应接触带）→ 多点面接触、无 EPA 抖动；**外壳 × {盒/球/外壳} 走 GJK/EPA**
   取一次法线，再用外壳近接触面顶点细化成 ≤4 点流形（`feature = 顶点序号+1`，点云序
   稳定 ⇒ warm 缓存可续接）。
3. **高斯喷溅 = 提供者**（`vxl-phys-splat` 的隐式场 σ=Σ核，SDF `(τ−σ)/|∇σ|`），
   **复用同一 `contacts_point` 通道**——不为喷溅新增形状，也不让窄相认识喷溅类型。
   物理参数与渲染参数同源（`export_splats` 直出）。
4. **凸体切割**是装载期操作（`fracture_voronoi_hull` + `spawn_hull_pieces`）：预断裂
   的碎块各自是独立刚体，撞击即自然散架——绕开「运行时删除体」这一引擎级改动。

## 后果

- 好：既有形状路径逐位不变（哈希基线未动）；新增域全是「提供者 + 一个形状变体」，
  模块 DAG 不反依赖；演示/转储/渲染全在引擎外（headless 纪律保持）。
- 代价：外壳对每对重建支撑体（O(n) 拷贝，未缓存）；外壳 × 高度场不受理；
  运行时删除/生成体的通用机制仍缺（预断裂是绕行，不是解决）。
- 待办：trimesh 提供者（非凸网格）、支撑缓存、喷溅场加速结构。
