# ADR 0007：回退匹配增加非距离门（深度跳变门 + 分离状态门）

- 状态：**accepted**（2026-09-14）
- 取代：无；**延伸** ADR 0003（0003 定「半径 1×skin」；本条加第二、三道门）

## 背景（Context）

ADR 0003 留下的硬限定：**任何距离类判别式都无法分开**「有害的回退匹配」与「塔
需要的回退匹配」（两者都在 1cm 内）；且全局开关已实测两极（关掉修好堆族、崩掉塔）。
下一轮入口因此锁定为**非距离信号**（OPEN-PROBLEMS P1 候选①）。

本轮先踩了一个方法论坑：第一版门写成「有效深度（`depth0 + sep·n`）与本帧裁剪
深度之差 ≤ 阈值」⇒ **零效果**。根因：锚点随体刚性移动时 `depth0 + sep·n ≡ cp.depth`
恒成立（实测差 ≤1e-6）⇒ 恒真式不是判别式。**教训：加门之前先验证判据在数据上有
方差**（本轮靠插桩才发现）。

插桩（回退接受处打印 `d/d0/dd/r/pn/pt`）拿到两类真信号：
- **瞬态型**（125 体复现 t≈5–10）：锚点在分离态烘焙（`d0=−3.7mm`）后被拿去触地帧
  用（`d=+0.2mm`）⇒ 深度跳变 **dd≈3.9mm**，携带加载相冲量 `pn≈13`；
- **极限环型**（t>30）：dd 小（µm）但切向冲量贴锥（`|pt| = μ·pn`）。

## 决定（Decision）

回退（特征未命中）分支的接受条件增加两道**非距离**门（`build_constraint`）：

1. **分离状态门**：`cp.depth > FB_DEPTH_MIN (=0)` ——分离/预期接触不继承暖冲量；
2. **深度跳变门**：`|cp.depth − w.depth0| ≤ FB_DEPTH_JUMP (=0.25mm)` ——直接量
   「本帧裁剪深度 − 锚点烘焙深度」，拒「刚触地型」错配。

阈值 0.25mm 由扫描选定（125 体复现 dE 峰值：1mm=63.8、0.5mm=27.8、**0.25mm=18.2**、
0.1mm=17.7；全拒=16.2 但塔崩），且物理含义自洽：`dd ≈ v·dt` ⇒ 只对「深度变化快于
~1.5 cm/s」的接触拒配，与睡眠阈（4 cm/s）同量级。

**同轮否掉、不引入**（详见 EXPERIMENTS.md）：切向锥饱和门（无变化）、分离门单独
使用（无变化）、⑦未承载不回拉（历史效果不复现）。

## 后果（Consequences）

- **正向**：125 体复现 dE 峰值 148.9→**18.2**（达标 ≤20）；pile5 入睡 1195→**1700/2000**；
  tower25 |v| 0.283→**0.236**、|Δpos| 0.0595→0.0590、塔身完整；`m0_gates` 末态全睡
  保持 0；T4 4.80× 且逐位一致。
- **代价（如实记）**：col45 位置 0.0065→**0.0105 m**（临界阈 45→42 体；仍在 T5 收紧
  口径「≤0.1m 且 ≤1% 塔高」内）；哈希按行为变化更新（m0_gates `0x443778a6…`→
  `0xbdf0cee6…`、stress `0x067ed531…`→`0x2cc8c488…`、determinism `0x7684f708…`→
  `0x8142fe05…`）。
- **未解**：125 体复现末态仍 125/125 不睡——极限环由「各项门都拦不住的」携带维持
  （dd 小、不贴锥、正深度）。下一轮入口见 OPEN-PROBLEMS P1（候选③ 帧间冲量幅值门）。
- 门是**回退分支专属**：特征 ID 精确匹配路径不动（最小行为面）。
