# ADR 0008：互操作层落位 core（四接口 + `Aabb` 下移）

- 状态：**accepted**（2026-09-14）
- 取代：无；被取代：无

## 背景（Context）

路线口径（`ROUTE.md`）把「兼容」定为第一轴：任意两域耦合**只能**走共享接口，
禁止域内特判。落地前的两个结构障碍：

1. **没有接口**：跨域能力（介质采样、接触查询、表示转换、约束元素）此前只存在于
   各自的域 crate 里，任何跨域功能都会退化成「直接调对方内部」。
2. **`Aabb` 位置不对**：包围盒定义住在 `vxl-phys-broad`，而它是宽相/地形/互操作层
   共用的纯数学类型；接口 trait 若要引用它，域 crate 就得依赖 broad ——
   违反 ROUTE §5 的「域 → core/interface」单向依赖。

## 决定（Decision）

1. **`Aabb` 下移到 `vxl-phys-core`**（含 `union_aabb` 助手）；`vxl-phys-broad`
   以 `pub use vxl_phys_core::Aabb;` 再导出 ⇒ **所有既有调用点零改动**
   （构建/测试/哈希全绿验证）。
2. **四接口落位 `vxl-phys-core::interop`**（跨域唯一通道）：
   `CollisionProvider`（bounds / closest_point / contacts_box，含盒角点采样默认实现）、
   `MediumField`（sample / deposit，双向耦合的唯一通道）、
   `StateBridge`（kind / export_positions / import_positions）、
   `ConstraintElement`（kind / bodies / is_active；**M2 定案草案**，M1 不接线）。
   规范类型：`SurfaceHit`、`InteropContact`、`MediumSample`、`BridgeKind`、`ElementKind`。
3. **纪律**：接口只依赖 core 类型；**域的具体类型不得出现在 interop 模块**
   （实现一律写在域 crate 内）。互操作层是**纯新增**——不接引擎既有管线，
   落地时 `m0_gates` 哈希逐位不变（已验）。
4. 首个真实实现：`impl CollisionProvider for HeightField`（narrow crate，复用
   既有双线性采样 + 解析法线），带 4 项测试（flat 最近点/盒底面 4 角穿透 0.1/
   斜坡法线逆坡/场外 None）与接口层 2 项测试（角点采样/预期接触带）。

## 后果（Consequences）

- 正面：M2「互操作核心」有了接口落点；后续体素 SDF / trimesh / 喷溅场只需
  `impl CollisionProvider` 即可被刚体接触消费；介质耦合（浮力/风）有唯一通道；
  表示转换（含 ROUTE §3.1 的喷溅渲染桥）有挂点。
- 代价/风险：`ConstraintElement` 的**求解期状态视图**尚未定稿（它是「一个求解器
  核心、多种元素」的关键接缝）；M1 内不接线，M2 与求解器接口一并定案——在此之前
  该 trait 只是能力声明，不代表可直接实现。
- 未做：现役窄相（SAT/GJK/高度场）与地形账本尚未真正「经 provider 路径」工作
  （它们仍走既有内部路径）；迁移属 M2 工作项（要求行为逐位不变）。
