# ADR 0004：确定性域——本机/同编译器逐位一致，哈希门禁守门

- 状态：**accepted**（2026-09-14）
- 取代：无；被取代：无

## 背景（Context）

SPEC §5 要求确定性。行业参照（Rapier 官方文档）：Rapier 只承诺
「locally deterministic」——同机、同版本、同编译器、同初始化顺序才逐位一致；
跨机要开 `enhanced-determinism` 且与 SIMD 互斥（lane 宽度自成确定性域），
跨平台还须 IEEE 754-2008 与跨平台超越函数。本仓的差异化承诺是**跨平台哈希门**
（V2 §5），但工程上一切逐位验证（岛序颠倒、分组重排、SIMD 落地）都以
「同机同编译器」为预言机。

## 决定（Decision）

1. **工程域**：M0–M1 内一切「行为等价」判定 = 同机 release 双跑四哈希
   （m0_gates / stress / determinism / T4 碎片雨）逐位一致。哈希值本身记入
   M0-GATES/M1-PLAN 基线；**行为改变（非等价改动）允许换哈希**，但必须在落地
   记录里显式写出新旧值与原因（例：ADR 0003 落地后 m0_gates
   `0xfd70f215…` → `0x443778a6…`）。
2. **跨平台承诺**：V2 §5 的跨平台哈希门在 M1 内**不验证、不承诺**；涉及浮点
   求值顺序的一切改动（SIMD、Jacobi 化、迭代序、并行分组）若改序，属 (a) 类
   行为变化，须按 ADR 0002 的量化流程与金样容差表重验，而不是靠「推理等价」。
3. 岛间无耦合是本域内已证明的事实（判定实验：逐岛处理顺序整体颠倒 ⇒ 四哈希
   逐位不变；配合断言验证岛体集合不相交）——岛级并行、岛分组重排因此合法。

## 后果（Consequences）

- 正面：判定成本低（两行改动即可当判定实验用，见 KNOWLEDGE.md「两行判定法」）；
  并行/SIMD 落地有硬预言机，已两次抓住真 bug（lane 相位耗尽错位、
  未验证提交的独立审计）。
- 负面：跨机复现（联机对战/回放跨端）在 M1 内不可用；IEEE 跨平台核验推到后续
  里程碑。
