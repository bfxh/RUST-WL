## 0. 一句话

四块地形提供者的**接触深度口径**统一成"正 = 穿透"（修三处），并给每一处都对上了
**双向验收**（贴住 + 可恢复）与 **`cargo test` 守卫**；保真/睡眠轴第一次有了**自动门**
（金样 harness 自带冻结基线；`scripts/gate_all.sh` 一条命令跑全量）；期间**六条假设被自己的
测量否证**（详见 EXPERIMENTS）。

## 1. 睡眠/保真轴（起点是"塔不入睡"那条线）

- **T5 金样"入睡列 ❌"是陈旧读数**：复测 = col45 **45/45**、pile5 **2000/2000**、
  tower25 **2396/2500（95.8%）**、超阈仅 `0/1/0`。旧行写的 `35/45、1195/2000、0/2500`
  是睡眠修复**之前**的数。
- **塔的 `Δpos` 是"有界偏移"不是漂移**：同一配方 600/1200/2400/4800 tick 四点 `max|Δpos|`
  **全部 = 0.0950 m**、mean 0.0571–0.0574 ⇒ 前 600 tick 内冻结（参照体落位后位姿不再变）。
  ⚠️ 口径：该度量＝"与 rapier 的位姿分歧"，只覆盖 **n=16 参照体**；59.5 mm 那个旧容差
  是别的配方下记的 ⇒ 建议按 ADR-0004 以 0.0950/0.0572 重设基线。
- **塔尾仍在收敛、不是卡住**：4800 tick 入睡 **2465/2500（98.6%）**、超阈 角3；
  但**没有任何一帧全睡**（尾部的 `|ω| ≈ 0.04–0.05` 正压 0.05 门线）⇒ 这是 P1 残余的最后一段。
- **`detect_once_per_tick`（tick 内复用流形）重测判死**：仓里注记写着"值得重测"，实测**双输**
  （默认档 Σv² +32%、金样 pile5 入睡 1994/2000 且**更慢** 5.93→7.67 ms/tick、T4 无变化）
  ⇒ 开关保持 `false`，结论写进该函数注释。

## 2. 提供者接触深度口径（本会话的净收益主体）

**契约**：`InteropContact.depth` = **穿透量**（正 = 体已在地表里侧），带内判据统一
`depth > −skin`。**高度场**路径本来就是这口径；**网格 / 体素点查询 / 喷溅**三处写成
`depth = skin − 距离`（外侧也给正 depth ⇒ 求解把体顶到 `sd ≈ skin` ⇒ **静置悬空一个皮肤带**）。

| 域 | 症状（实测） | 修法 | commit |
|---|---|---|---|
| 网格点/盒 | 平网格盒 **y 0.3849**（该 0.35）、起伏网 +0.019…+0.021 | `depth = −sd` | `c6090d5` |
| 体素点查询 | **外壳**悬空 **+0.0220**（盒/球本来就对） | `depth = −sdf` | `99c892f` |
| 喷溅点查询 | 盒悬空 **+0.0086/+0.0115** | `depth = −f` | `4d6374f` |

**双向验收**（每处都做）：① **贴住**——平网格盒 0.3500（精确）、体素外壳 −0.0002、
喷溅盒 −0.0045/−0.0029；② **可恢复**——arena `shape-trimesh-sunk` 仍 PASS（vxl **21/0/0**）。
**流体无损**：`vxl-phys-fluid` 两处 provider 查询**不读 depth**（自算 sdf、按管道半径过滤）
⇒ `dam_break` 读数逐字相同（实测）。

**守卫进 `cargo test`**（`crates/vxl-phys/tests/rest_height_contract.rs`，四处修复全覆盖）：
网格盒 / 体素外壳 / 喷溅盒 / 网格球顶出。**每一条都验过"会红"**（把对应口径临时写回旧式 ⇒
分别 FAILED 出 `+0.0274`、`+0.0220`、`+0.0209`），随后 `git diff --exit-code` 确认逐字恢复。

## 3. P5 收官（三角网"末态能量异常"不是引擎缺陷）

- 原症状（默认档 trimesh Σv² ≈ 1e5、"约 5% 体穿网"）：加"**离场轨迹**"读数后判明
  ——10–14 个体**滚出 ±45 m 地形边缘**后自由落体（离场瞬间 |v| 仅 9–14 m/s、竖直=自由落体分量），
  场景 `i%3` 有 ~134 个**会滚的球/圆柱**且**没有边界** ⇒ `Σv²` 只是"掉出去几个体"的计数。
  **修的是指标**：`arena_bench` 现在同时报"有效量（剔除 y ≤ −5）"——实测 **有效 92.7 vs 总量 1.4e5**。
- **球"埋在地表下 1.09 m"**：独立仪器（探针自己暴力枚举全部三角形算 clearance）判明是
  **参考点错位**——球在粗网格上**滚了 17 m**，却拿**投放点**的 `h` 比 ⇒ 澄清 `−0.009…−0.012`
  （贴着，在皮肤带内）。⇢ 详见 EXPERIMENTS。
- **教训（本会话最重要的一条方法论）**：凡"体在错误高度/位置"的读数，**必须**用与位置无关的
  判据复核（`clearance = d_min − r`、全身采样最小间隙、接触集自身、离场轨迹）。

## 4. P6 喷溅域（新立项 → 机理 → 修复）

- **立项**：修口径时发现"盒贴住、球反常"——深埋 0.02/0.10/0.20 m 的球**完全不动**（|v|=0），
  0.30 m 却给**恰好 3.0 m/s** 弹出。（睡 vs 不睡对照逐位相同 ⇒ 排除睡眠。）
- **机理**：`density_grad` 的**逐核截断**（`if a > cut { continue }`）⇒ 点离所有核超过
  `σ√cut` 时 `s=0,g=0` ⇒ `sdf()` 走退化分支给 `+√iso = +0.7071`（**符号翻成外侧**）⇒ 不生成接触。
  那记 3.0 m/s = `0.05 m / dt`（单 tick 去穿透上限）的截断冲量。
- **修复**：`cut` 由 3σ 提到 **4σ**，且**四处耦合一起改**（`density_grad` 截断 /
  `rebuild_grid` 的 bin 与登记范围 / `world_bounds`）；**余量规则**写进模块头
  （`σ(√cut − 1.31) ≳ 最大查询偏移`）。收敛实测：3σ 面偏低 **8.5 cm**、4σ 偏低 **3 mm**、
  5σ 精确；开销 4σ ≈ 2×。
- **续修**：`sdf` 近场**牛顿投影**（3 次迭代，按成本/精度实测选）⇒ 球"沉 ≈0.4·r"清零
  （−0.093/−0.167 → **−0.021/−0.013**），盒读数逐位不变。
- **顺带**：`arena_bench` 的 `Σv²` 加"有效量"（见 §3）。

## 5. T4 碎片雨并行扩展（数据/取舍都换了口径）

- **饱和真因**：本机 8P+16E 上 ~2.5× 饱和；逐项**否证**负载不均（每组流形 590/591/592）、
  串行占比、spawn 开销（本机 192 µs/次）、E 核拖尾（8 组同速）⇒ **访存受限**
  （并发每上一档，每线程单位工作量成本涨一档：**ns/流形 0.97→1.22→1.49→2.45**）。
  ⚠️ 当天晚些的算式**把"带宽"这个标签也否证了**（四相位达成吞吐仅 1–2 GB/s，远未饱和）
  ⇒ 正确说法是**延迟受限**；见 `OPEN-PROBLEMS` 上方"共同真因 + 同日修正"节。
- **靶子换对**：解算相位里**约束构建占 97%**、迭代仅 3%（收敛早退生效）
  ⇒ "降查找"（warm 索引换快哈希）**实测无收益**（+3.5% 在噪声内）⇒ 回退。
- **分母统一**：`IslandDiag` 增**每解算**三段合计；判据改成**窗口均值的 ns/流形、ns/点**；
  并量出"每流形成本随**工作集**变 11–18×"（热 **54 ns** vs 流式 **604–970 ns**）
  与该场景的**三阶段**（下落 → 落定峰值 → 睡眠塌缩：末帧流形 11836 → 707）。
- 三条候选：① 跨子步共享约束 —— T4 ② 减每点构建量（**分母已干净，待立项**）
  ③ 旋转缓存 —— 估算否证（1.5–3%）。

## 6. 门禁自动化（本会话的第二个净收益）

- **金样门**（`gold-sample` harness **自带冻结基线自检**）：与基线同配方时逐项比对
  入睡/超阈/Δpos，不符即 `❌ … ≠ 基线 …` + **`exit 1`**；换任一旋钮则"跳过"并 exit 0
  （实验不受影响）。基线：col45 `45/45, 0/0/0, 0.0034/0.0016`、pile5 `2000/2000, 0/0/0, 0.0041/0.0020`、
  tower25 `2396/2500, 0/1/0, 0.0950/0.0572`。**它第一次发挥作用就是本轮**：打开复用开关后
  立刻报出 pile5 `入睡 1994 ≠ 2000；超阈 1/1/2 ≠ 0/0/0`——放在昨天没人会注意到。
- **全量门**：`bash scripts/gate_all.sh`（主仓五项 + 行为门 + 金样门），逐项贴退出码、
  失败带日志尾部；`m1_islands` 为 **report-only**（本机 ≥3× 结构性达不到），但它的
  "串行/并行末态哈希逐位一致"照样判。两扇门的**失败传播都实测过**。
- **为什么做**：金样读数此前**只写在文档里、没有门看着** ⇒ 陈旧到差一倍都没人发现。
