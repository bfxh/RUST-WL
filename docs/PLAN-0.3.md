# PLAN 0.3 —— 液体域首切片（CPU WCSPH，SPEC §4.8）

## 0. 口径

- 目标：ROUTE 域表「液体 / 软体 / 布」行的**液体**块起步——`vxl-phys-fluid` 从参数
  骨架变为可跑的 WCSPH 粒子流体（CPU 档第一块）。
- 不做（本切片明确排除，后续切片）：
  - 刚体 ↔ 流体双向耦合（Akinci 边界粒子）——切片 2；
  - GPU PBF / FLIP-APIC 档——M4；
  - 自适应核长 / 大变形自由面修正。
- 三轴对齐：
  - **兼容**：流体-边界复用统一提供者通道 `CollisionProvider::contacts_point`
    （体素/三角网/喷溅即插即用，不另造边界接口）；
  - **性能**：邻居 = 均匀网格（格边 = h，27 邻域），复用喷溅网格模式；
  - **真实化**：Tait 状态方程 + XSPH 黏度；静水压强物理自洽可验证。

## 1. 方法（确定性优先）

- **核**（Monaghan 族，文档化常数）：
  - 密度：poly6 `W(r) = 315/(64πh⁹)·(h²−r²)³`（含自身项）；
  - 压力梯度：spiky `∇W(r) = −45/(πh⁶)·(h−r)²·r̂`（中心不减益 ⇒ 抑制张力不稳定，
    对应配置 `tensile_instability_suppression`）；
  - 黏度：XSPH 速度平滑 `v_i += ε·Σ m/ρ_j·(v_j−v_i)·W(r)`（ε = `xsph_viscosity`）。
- **状态方程**：Tait `p = B·((ρ/ρ0)^γ − 1)`，γ = 7，`B = c²ρ0/7`，
  c（声速）入配置；压强不钳负（Tait 天然 ≥ −B，负压允许到小幅）。
- **质量标定**：初始化时按粒子晶格（间距 d = h/2）反解 `m = ρ0 / Σ_lattice W`，
  使静止晶格密度恰为 ρ0（标准做法，避免初态漂移）。
- **积分**：半隐式欧拉，固定子步 `dt = 1/60 / substeps`（`substeps` 入配置，默认 4）。
- **确定性**：
  - 邻居遍历 = 27 邻域按格坐标序 + 格内按粒子索引序 ⇒ 求和序是位置的确定函数；
  - 无 f64、无 fast-math、`forbid(unsafe_code)`、全 f32 严格;
  - 确定性判据：同输入两次运行位置**逐位相等**（`to_bits()`）。
- **边界**：粒子逐个查询已注册边界提供者的 `contacts_point(p, skin, out)`，
  depth > 0 ⇒ 位置沿法线推出 + 法向速度归零（非弹性，e = 0）；skin = 0.6h。
  - （实装修订）skin 定为 **0.015 = 0.15h**（0.6h 会在盆角过度吞粒）；查询走
    门面新增的 `contacts_point_boundary` 专用通道（默认逐位委托
    `contacts_point`，体素提供者覆写为终版口径——试错史见 §4.1）。

## 2. 结构

- `FluidSystem`（SoA：pos/vel/dens/press + 网格）：
  - `new(config, |bodies, spacing)` → 晶格盒状初始化 + 质量标定；
  - `step(dt, providers, &boundaries)`：建网格 → 密度 → 压强 → 力/黏度 →
    积分 → 边界投影；
  - `positions()/velocities()/len()` 只读视图（渲染桥 / 测试）。
- 门面：`World::add_fluid(sys, boundaries) -> usize` + `fluid_pass`
  （体解算后按固定子步推进；本切片流体不反作用刚体）。

## 4. 预期与实测（2026-09-15 回填）

**落地**：`vxl-phys-fluid` WCSPH 全链路（§1 全部机制）+ 门面 `add_fluid` /
`fluid_pass`（体解算后推进，切片 1 单向耦合）。测试 7/7（§3 表全过，其中 #2
静水压按实测口径诚实重写，见 §4.3）；四哈希门禁逐位不变 ⇒ 刚体管线零扰动。

**性能**（release 实测）：showcase 六域同场 320 流体粒 ×4 子步 ≈ +2 ms/tick
（全场景 4.23 ms/tick，236 FPS）；`dam_break` 504 粒 3.80 ms/tick（263 FPS）。
均远低于预算；瓶颈仍是邻居求和（27 邻域 CPU 档预期内）。

### 4.1 边界口径试错史（三次误诊，终版 `contacts_point_voxel_solid`）

1. **首查「盆泄漏」实为零厚度墙 typo**：测试盆某壁 `fill_box` min==max ⇒
   厚 0 的墙。零厚度面不可驻留，粒子穿出。修掉 typo 后仍有泄漏 ⇒ 不是根因全体。
2. **截断 SDF 门误报 ⇒ 外壳面外向棘轮**：旧口径 `contacts_point_voxel` 以
   SDF 符号判内外；截断 SDF 在壳体近面内侧被误报为「外部」（正 sdf）⇒ 内点
   被当穿透沿「最近面」推出壳面，逐 tick 单向外移不可回，形成棘轮。
3. **终版**（`vxl-phys-terrain` 新增，旧口径保留供外部 provider 委托）：
   - 内外判据 = **格占据位图**（`grid_of` + `get`），不用 sdf 符号；
   - 内点恒推向最近**开放面**（邻格在网格内且为空 = 流体可达）；出网格的
     壳面仅作回退；两不可再回退截断 SDF；
   - 删除「新穿透原路推回」特例（近壳处同样形成外向棘轮）。
   - 门面 `ProviderColliders::contacts_point_boundary` 默认 trait 方法：
     默认逐位委托旧 `contacts_point`，体素提供者覆写走终版。
   实测：4×4×4 盆 300 tick 零穿壁、零外逸（门面门禁测试固化）。

### 4.2 驻留瞬态顶心喷泉（负面结论，未修，以铸装初值规避）

任何带落差的入盆水块（0.8 m 重落、0.1 m 轻落、触底就位**皆复现**）：底部
镜像鬼影密度尾（底压 ≈1.65× 静水，§4.3）⇒ 压实波在块顶心聚焦 ⇒ 顶心粒子以
近钳制速度（实测 ~9 m/s，vmax≈9.6）垂直喷过敞口盆顶。**不是边界失效**——
全部场景零穿壁；这是显式压缩求解器的驻留瞬态。抑制 = **铸装近平衡初值**：
水块按沉降后几何反推晶格直接就位（门禁口径 [8,8,5]@0.25 对 0.4 盆腔，
showcase 石盆同款 [8,8,5]@0.05），瞬态消失。

**自由柱对照（`dam_break` 实测）**：紧凑盆（1.5×1.5 m 内域）内 0.25×0.25×0.65
自由水柱 504 粒——前 2 tick「闪塌」（柱顶 1.70→1.32，初值压缩释放），波前
~2.6 m/s 近匀速推进，~2.7 s 扫满全盆；全程 y ≥ 1.000（零穿底）、终态
x∈[−0.75, 0.75] = 恰为内域（零越堰），仅 1 粒受瞬态喷出后回落。塌坝**本就该
飞溅**，自由柱是演示口径；与门禁的铸装口径相区分。大盆（7×7 m）对照：同一
水量摊成 1–3 mm 水膜（渲染为散点）⇒ **演示尺度定律：0.063 m³ 水配 ≈1.5 m
内域盆**（水层 ~30 mm，粒距 ≈ 软团半径 ⇒ 连续水面）。
